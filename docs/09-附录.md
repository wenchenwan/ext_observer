## B. 术语表

| 术语 | 英文 | 解释 |
|---|---|---|
| 外部力矩 | external torque | 机器人与环境接触产生的、折算到关节上的力矩 |
| 观测器 | observer | 根据可测量的量估计不可测量的量（这里是 $\tau_{ext}$）的算法 |
| 广义动量 | generalized momentum | $p = M(q)\dot q$ |
| 斜对称性 | skew-symmetry property | $\dot M - 2C$ 是反对称矩阵，等价于 $\dot M = C + C^T$ |
| Christoffel 符号 | Christoffel symbols | 由 $M$ 的偏导数构造 $C$ 的标准方法 |
| RNEA | Recursive Newton-Euler Algorithm | 递归牛顿-欧拉算法，高效计算逆动力学 |
| 驱动增益 | drive gain | 电流到力矩的比例系数 |
| 残差 | residual | 动量观测器的输出 $r$ |
| super-twisting | super-twisting algorithm | 一种二阶滑模算法，输出连续、有限时间收敛 |
| 抖振 | chattering | 滑模控制中由于不连续切换造成的高频振荡 |
| 双线性变换 | bilinear / Tustin transform | 一种把连续传递函数转换为离散传递函数的方法 |
| 预畸变 | prewarping | 补偿双线性变换频率压缩，使截止频率准确 |
| Van Loan 方法 | Van Loan's method | 用增广矩阵的矩阵指数计算离散过程噪声协方差 |
| 幂零矩阵 | nilpotent matrix | 某次幂为零的矩阵，其矩阵指数的泰勒级数有限项即精确 |
| 无差拍 | deadbeat | 离散系统在有限步（通常一步）内收敛，极点在原点附近 |
| ODR | One Definition Rule | C++ 单一定义规则 |
| 自适应阈值 | adaptive threshold | 随运动状态变化的碰撞检测阈值 |

## D. 常见问题

**Q1：第一次调用 `getExternalTorque` 为什么总是返回 0？**
第一次调用只用来初始化内部状态（积分器初值、滤波器稳态、卡尔曼初始状态），见 [03 §4](03-架构与接口.md#4-观测器的生命周期)。

**Q2：机器人静止不动，外力估计却不为 0，为什么？**
静止时 $\hat\tau_{ext} \approx G_{模型} + \tau_{f}(0) - \tau$，也就是重力模型误差加上摩擦偏置 $F_0$ 的误差。检查驱动增益、重力相关的参数，以及摩擦模型在零速时的取值。

**Q3：每次速度换向时都出现一个尖峰，怎么办？**
这通常是库仑摩擦 $F_c\,\mathrm{sign}(\dot q)$ 的跳变造成的，用平滑函数代替 sign，见 [07 §2.4](07-集成与调参指南.md#24-摩擦模型)。

**Q4：输出突然变成 NaN，而且一直是 NaN？**
很可能是某一步 `dt = 0`，见 [08 P3](08-已知问题与修复建议.md#p3-dt--0-导致-nan-永久污染)。调用 `reset()` 可以恢复，但要从源头保证 `dt > 0`。

**Q5：动量观测器的输出越来越大，最后发散？**
检查 $K_O\Delta t < 2$，见 [05 §1.6](05-观测器详解.md#16-离散稳定性kδt--2)。

**Q6：高速运动时出现虚假外力，低速时正常？**
可能有两个原因：(1) `getC()` 返回的不是 Christoffel 形式的 $C$（[02 §4.3](02-理论基础.md#43-反例用错-c-会怎样)）；(2) 科氏/离心相关的模型参数误差较大。先用 [02 §4.4](02-理论基础.md#44-检验方法) 的方法检查 $C$。

**Q7：动量观测器和 FDyn 该选哪个？**
它们在连续时间上等价（[02 §5.1](02-理论基础.md#51-一个重要结论动量观测器与-fdyn-在连续时间上完全等价)），只是离散化方式不同。FDyn 无条件稳定，但要注意 `dt = 0`；动量观测器对 `dt = 0` 安全，但要求 $K_O\Delta t < 2$。

**Q8：可以在多个线程中使用吗？**
每个线程要使用各自的观测器和机器人对象，见 [03 §5.4](03-架构与接口.md#54-线程安全)。

**Q9：链接时报 `multiple definition`？**
同一个观测器头文件被多个 `.cpp` include 了，见 [03 §6](03-架构与接口.md#6-header-only-与-odr-约束) 和 [08 P6](08-已知问题与修复建议.md#p6-头文件中的函数没有-inline多文件项目链接失败)。

**Q10：`DKalmanObserverExp` 的结果每次运行都不一样？**
这是 [08 P1](08-已知问题与修复建议.md#p1-kalmanfiltercontinous-读取未初始化内存) 读取未初始化内存的典型症状，加一行 `AQ.setZero();` 即可修复。

**Q11：怎样把 `dynamic_calibration` 的结果用在这个库里？**
推荐用基回归矩阵实现 `rnea()`，见 [07 §2.2](07-集成与调参指南.md#22-方式-a用基回归矩阵实现-rnea推荐)。
