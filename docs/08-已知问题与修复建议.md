### P1 KalmanFilterContinous 读取未初始化内存

**位置**：[lib/kalman_filter_continous.cpp:46-51](../lib/kalman_filter_continous.cpp#L46-L51)

**现象**：Van Loan 增广矩阵 `AQ` 的左下块从未赋值：

```cpp
// [-A Q; 0 A']
AQ.resize(na+na, na+na);          // 从 1×1 扩展到 2na×2na，Eigen 重新分配内存且不初始化
AQ.block(0, 0, na, na) = -a;
AQ.block(0, na, na, na) = Qd;
AQ.block(na, na, na, na) = a.transpose();
// 左下块 AQ.block(na, 0, na, na) 是内存中的残留值
```

**证据**：

- 注释明确写着左下块应该是 `0`；
- 紧邻的 `AB` 在 `resize` 后调用了 `setZero()`，`AQ` 没有；
- `AQ` 在初始化列表中是 `MatrixXd(1, 1)`，`resize` 到更大尺寸时必然重新分配，Eigen 不会初始化新内存；
- `DKalmanObserverExp` 是 [matlab/test.m](../matlab/test.m#L106-L126) 中唯一被整段注释掉的观测器。

**后果**：Van Loan 方法依赖左下块为零（这样矩阵指数才是块上三角的），垃圾值会污染 $Q_d$，使 `DKalmanObserverExp` 的结果不可信，并且**每次运行的结果可能不同**。

**修复**：

```cpp
AQ.resize(na+na, na+na);
AQ.setZero();                     // ← 添加这一行
AQ.block(0, 0, na, na) = -a;
```

### P2 动量观测器在 KΔt ≥ 2 时发散且没有任何检查

**位置**：[lib/momentum_observer.h:70-96](../lib/momentum_observer.h#L70-L96)

**现象**：离散实现的误差动态为 $e_k = (1-a)e_{k-1} - ae_{k-2}$，$a = K_O\Delta t/2$，稳定条件是 $K_O\Delta t < 2$（推导见 [05 §1.6](05-观测器详解.md#16-离散稳定性kδt--2)）。构造函数和 `settings()` 都不检查这一点，`dt` 由调用方每步传入，也无法在构造时检查。

**证据**：$\Delta t = 0.01$ 时，$K_O = 201$ 的最大输出为 1.12，$K_O = 250$ 达到 $1.9\times10^9$（[06 §4.3](06-测试与验证.md#43-动量观测器的稳定边界)）。

**修复建议**：

1. 在文档中注明 $K_O\Delta t < 2$，推荐 $\le 0.5$；
2. 或在 `getExternalTorque` 中加入调试断言：

```cpp
assert((ko.array() * dt < 2.0).all() && "MomentumObserver: K*dt must be < 2");
```

3. 如果控制频率不稳定，可以改用 FDyn，它与动量观测器等价但无条件稳定（需同时处理 P3）。

### P3 dt = 0 导致 NaN 永久污染

**位置**：[lib/iir_filter.h:165-173](../lib/iir_filter.h#L165-L173)（`FilterF2::filt`），[lib/kalman_filter_continous.cpp:94](../lib/kalman_filter_continous.cpp#L94)

**现象**：

```cpp
Eigen::VectorXd FilterF2::filt(Eigen::VectorXd& x, double dt) {
  f2 = 2/dt;                          // dt = 0 → +∞
  omega = tan(cut*dt*0.5);            // → 0
  k2 = -f2*omega*omega/(1+omega);     // → −∞ × 0 = NaN（IEEE 754）
  return filt(x);                     // y1 变为 NaN，之后永远是 NaN
}
```

`KalmanFilterContinous::makeDiscrete` 中的 `Rd = Rupd / dt` 在 `dt = 0` 时得到无穷大，也会导致 NaN。

**受影响**：`FDynObserver`、`FDynObserverRnea`、`FRangeObserver`、`DKalmanObserverExp`。只有在第一次调用之后传入 `dt = 0` 才会触发，因为第一次调用不使用 `dt`。

**证据**：`inf * 0.0` 在 IEEE 754 中结果为 NaN（已在 Python 中验证）；NaN 一旦进入 IIR 滤波器的状态 `y1`，就会通过 `y1 = k1*y1 + ...` 永久传播。

**触发场景**：驱动器重复发送同一帧数据、时间戳分辨率不足、或者调用方用 `now() - last` 计算 `dt` 时两次调用落在同一个时钟刻度内。

**修复**（任选其一）：

```cpp
// 方案 1：调用方保证（推荐，同时修复所有观测器）
if (dt <= 0) return last_ext;          // 跳过这一帧

// 方案 2：在滤波器中防护
Eigen::VectorXd FilterF2::filt(Eigen::VectorXd& x, double dt) {
  if (dt <= 0) return y1;              // 保持上一输出
  ...
}
```

### P4 cutOffHz / sampHz 参数名与实际单位不符

**位置**：[lib/filtered_dyn_observer.h:13](../lib/filtered_dyn_observer.h#L13)、[lib/filtered_range_observer.h:13](../lib/filtered_range_observer.h#L13) 及对应的 `settings()`、RNEA 版

```cpp
FDynObserver(RobotDynamics *rd, double cutOffHz, double sampHz);
```

**实际单位**：

| 参数名 | 名字暗示 | 实际 | 证据 |
|---|---|---|---|
| `cutOffHz` | Hz | **rad/s** | `tan(cutOff*sampTime*0.5)` 要求 $\omega T/2$；[matlab/test.m:131](../matlab/test.m#L131) 注释写 `% rad/s` |
| `sampHz` | Hz（采样频率） | **s（采样周期）** | 底层 `FilterF1::update(double cutOff, double sampTime)`；[test.m:132](../matlab/test.m#L132) 注释写 `% s`；测试传入 `TSTEP = 0.01` |

**后果**：如果按名字传入 `(8 Hz, 100 Hz)`，截止频率会偏差 $2\pi$ 倍，采样周期错成 100 s。不过由于变步长版本每步都用实际 `dt` 重新计算系数，**`sampHz` 传错只影响首次 `set()` 使用的初始系数**（即 F2 初始状态的 $\omega_w$），影响有限；**`cutOffHz` 传错则会一直影响结果**。

**修复**：把参数重命名为 `cutOff`（rad/s）和 `sampTime`（s），与 `FilterF1::update` 一致。

### P6 头文件中的函数没有 inline，多文件项目链接失败

**位置**：`lib/` 下所有观测器头文件，以及 `iir_filter.h`、`kalman_filter.h`。

**现象**：成员函数在类外、头文件中定义，没有 `inline`。例如：

```cpp
// momentum_observer.h:56
MomentumObserver::MomentumObserver(RobotDynamics *rd, VectorJ& k) : ... { ... }
// momentum_observer.h:70
VectorJ MomentumObserver::getExternalTorque(...) { ... }
```

两个 `.cpp` 文件 include 同一个头文件时，链接器会报 `multiple definition`。现有代码之所以没问题，是因为每个程序只有一个编译单元 include 这些头文件。

**修复**：在每个类外定义前加 `inline`，例如：

```cpp
inline MomentumObserver::MomentumObserver(RobotDynamics *rd, VectorJ& k) : ... { ... }
inline VectorJ MomentumObserver::getExternalTorque(...) { ... }
```

需要修改的文件：`momentum_observer(_rnea).h`、`disturbance_observer(_rnea).h`、`sliding_mode_observer(_rnea).h`、`disturbance_kalman_filter(_rnea/_exp).h`、`filtered_dyn_observer(_rnea).h`、`filtered_range_observer.h`、`iir_filter.h`、`kalman_filter.h`。

### P7 freeAll 的 switch 多余且容易漏改

**位置**：[matlab/observers.cpp:27-70](../matlab/observers.cpp#L27-L70)

**现象**：`freeAll()` 用一个 `switch` 按类型 ID 把基类指针强制转换为派生类指针后再 `delete`。但基类 `ExternalObserverBase` 已经有虚析构函数（[external_observer.h:150](../lib/external_observer.h#L150)，由提交 `7e4cf07 Add virtual destructors` 加入），直接 `delete` 基类指针就能正确析构。

**风险**：`switch` 没有 `default` 分支。添加新观测器时如果忘了在这里加 `case`，该观测器不会被释放，而指针随后被置空，造成**静默内存泄漏**。

**修复**：

```cpp
void freeAll()
{
  for(int i = 0; i < _nextIndex; i++) {
    delete observer[i];          // 虚析构函数会调用正确的派生类析构
    observer[i] = 0;
  }
  _nextIndex = 0;
}
```

### P9 两份 observers.cpp 的矩阵读取顺序不同

**位置**：[tests/observers.cpp:164-176](../tests/observers.cpp#L164-L176)（外层循环是行，**行主序**）与 [matlab/observers.cpp:193-205](../matlab/observers.cpp#L193-L205)（外层循环是列，**列主序**）

**后果**：对同一个 C 数组，两者得到的矩阵互为转置。测试中 $S = 0$、$H = I$、$Q$ 和 $R$ 为对角阵，都是对称的，所以看不出差别；传入非对称的 $S$ 或 $H$ 时会出错。

**说明**：MATLAB 按列主序传递数组，所以 `matlab/observers.cpp` 的做法是正确的。从 C/C++ 调用时，要按列主序排列数组（[matlab/test_lib.cpp](../matlab/test_lib.cpp) 中的 `H = {1,0,0,1}` 是对称的，所以不受影响）。

### P10 卡尔曼观测器可以被拷贝，导致 double-free

**位置**：`DKalmanObserver`、`DKalmanObserverRnea`、`DKalmanObserverExp`

**现象**：这三个类持有裸指针 `filter`（构造时 `new`、析构时 `delete`），但没有禁用拷贝构造和拷贝赋值。编译器生成的拷贝只复制指针，两个对象析构时会 `delete` 同一个滤波器。

**修复**（任选其一）：

```cpp
// 方案 1：禁用拷贝
DKalmanObserver(const DKalmanObserver&) = delete;
DKalmanObserver& operator=(const DKalmanObserver&) = delete;

// 方案 2：用智能指针（同时去掉手写的析构函数）
std::unique_ptr<KalmanFilter> filter;
```

### P11 KalmanFilter 的两个 step 重载语义相反

**位置**：[lib/kalman_filter.h:52](../lib/kalman_filter.h#L52)、[63](../lib/kalman_filter.h#L63)

| 重载 | 期望的 `A`、`B` | 离散化 | `Q`、`R` |
|---|---|---|---|
| `step(u, y)` | 离散时间 | 无 | 每步 |
| `step(u, y, dt)` | **连续**时间 | 前向欧拉 | 每步（**不随 dt 缩放**） |

两个重载同名，签名只差一个参数，但对构造函数传入的 `A` 的含义要求完全相反；用错了不会报错。

**修复建议**：重命名为 `stepDiscrete(u, y)` 和 `stepContinuous(u, y, dt)`，或在构造时通过参数声明 `A` 是离散还是连续的。

### P12 KalmanFilterContinous::setCovariance 不更新 Rupd

**位置**：[lib/kalman_filter_continous.cpp:55-59](../lib/kalman_filter_continous.cpp#L55-L59)

**现象**：`setCovariance(q, r)` 只更新 `R`，而离散化时使用的是 `Rupd`（`Rd = Rupd / dt`）。`Rupd` 只在 `updateR()` 中更新，构造时被设为单位阵。所以如果直接使用这个类而不调用 `updateR()`，设置的 `R` 完全不起作用。

`DKalmanObserverExp` 每步都调用 `updateR(M)`，**不受影响**。

**修复**：在 `setCovariance` 中增加 `Rupd = r;`。

### P13 getC 的 Christoffel 要求没有文档说明

**位置**：[lib/external_observer.h:65-72](../lib/external_observer.h#L65-L72)

**现象**：接口注释只写了 “Get Coriolis/centrifugal matrix”。但除扰动观测器外，所有观测器都使用 $C^T\dot q$，这要求 $C$ 满足 $\dot M = C + C^T$（Christoffel 形式）。$C$ 的其他合法分解能给出相同的 $C\dot q$，却会给出不同的 $C^T\dot q$，观测器会因此输出随速度变化的虚假外力。反例见 [02 §4.3](02-理论基础.md#43-反例用错-c-会怎样)。

**修复**：在接口注释中注明这个要求，并建议使用者用 [02 §4.4](02-理论基础.md#44-检验方法) 的方法做数值检验。

### P14 示例参数不适合直接用于真机

示例参数是在**无噪声、模型准确**的仿真中选的，照搬到真机可能出问题：

| 观测器 | 示例参数 | 问题 | 详见 |
|---|---|---|---|
| 扰动 | σ=21, ξ=18, β=50（$k$=1059） | 离散极点 0.01~0.11，几乎不滤波，会把速度噪声放大到输出 | [05 §2.7](05-观测器详解.md#27-调参三个参数只合成一个-k) |
| 滑模 | $S_1$=[15,20]，100 Hz | 不满足 $T_2 > (50S_1+S_2)\Delta t$，有轻微抖振 | [05 §3.6](05-观测器详解.md#36-离散稳定性与抖振) |
| 卡尔曼 | $Q$、$R$ | 是 100 Hz 下的每步值，换控制频率要换算 | [05 §5.4](05-观测器详解.md#54-两套参数为什么差-100-倍) |
