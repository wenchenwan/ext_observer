# 05 · 观测器详解

> 本章逐个讲解 7 个观测器。每个观测器都按同样的结构展开：
> **一览卡片 → 理论推导 → 逐行代码 → 首次调用 → 稳定性 → 调参 → RNEA 版差异**
>
> 所有推导都从 [02 理论基础](02-理论基础.md) 的动量方程出发：
> $$\dot p = (\tau - \tau_f) - \beta + \tau_{ext},\qquad p = M\dot q,\qquad \beta = G - C^T\dot q$$
> 建议按顺序阅读：先读 §1 动量观测器，再读 §6 FDyn（两者等价），其余按需要阅读。

## 1. 动量观测器 MomentumObserver

### 1.1 一览

| 项目 | 内容 |
|---|---|
| 文件 | [momentum_observer.h](../lib/momentum_observer.h)（98 行）、[momentum_observer_rnea.h](../lib/momentum_observer_rnea.h)（101 行） |
| 来源 | De Luca 等人提出，是碰撞检测中最经典的方法 |
| 等效传递函数 | $\hat\tau_{ext} = \dfrac{K_O}{s+K_O}\tau_{ext}$（每个关节独立） |
| 参数 | `k`：每个关节一个增益 $K_{O,i}$，单位 1/s |
| 离散方法 | 梯形积分，积分项中使用上一步的残差 |
| 稳定条件 | ✅ 已验证：$K_{O,i}\,\Delta t < 2$ |
| 每步计算 | 1 次 $M$、1 次 $C$、1 次 $G$，无矩阵求逆 |

### 1.2 理论

定义**残差** $r$：

$$
r(t) = K_O\Big[\,p(t) - \int_0^t\big(\tau - \tau_f - \beta + r\big)\,ds - p(0)\,\Big]
\tag{1.1}
$$

两边求导，代入动量方程：

$$
\dot r = K_O\big[\dot p - (\tau - \tau_f - \beta + r)\big] = K_O\big(\tau_{ext} - r\big)
\tag{1.2}
$$

所以 $r$ 是 $\tau_{ext}$ 的**一阶低通滤波**，时间常数为 $1/K_O$。

**关键技巧**：式 (1.1) 中 $p$ 出现在积分号**外面**，本来需要对 $p$ 求导，现在被积分“抵消”了，整个计算中只有积分，没有微分。

### 1.3 逐行代码

[momentum_observer.h:70-96](../lib/momentum_observer.h#L70-L96)：

```cpp
VectorJ MomentumObserver::getExternalTorque(VectorJ& q, VectorJ& qd, VectorJ& tau, double dt)
{
  p = dyn->getM(q) * qd;                                    // ① p = M·q̇
  beta = dyn->getG(q) - dyn->getC(q, qd).transpose() * qd;  // ② β = G − Cᵀq̇

  torque = tau - dyn->getFriction(qd);                      // ③ τ − τ_f
  if(isRun) {
    torque += r - beta;                    // ④ 被积函数 f_k = τ − τ_f − β + r_{k−1}
    sum += 0.5 * dt * (torque + tprev);    // ⑤ 梯形积分：sum += Δt/2·(f_k + f_{k−1})
  } else {
    torque -= beta;                        // ⑥ 首次：f_0 = τ − τ_f − β（r = 0）
    r.setZero();
    sum = p;                               // ⑦ sum 初始化为 p(0)
    isRun = true;
  }
  tprev = torque;                          // ⑧ 保存 f_k，供下一步梯形积分使用

  p -= sum;                                // ⑨ p ← p − p(0) − ∫f

  for(int i = 0; i < jointNo; i++) {
    r(i) = ko(i) * p(i);                   // ⑩ r = K_O ⊙ (...)，K_O 是对角的
    torque(i) = r(i);                      // ⑪ 复用 torque 作为返回值
  }
  return torque;
}
```

| 变量 | 含义 | 注意 |
|---|---|---|
| `sum` | $p(0) + \int_0^t f\,ds$ | **一个变量同时承担两个角色**：首次调用时被设为 $p(0)$，之后不断累加积分。所以第 ⑨ 行一次减法就完成了 $p - p(0) - \int f$ |
| `torque` | 依次表示 $\tau - \tau_f$ → 被积函数 → 返回值 | 同一个变量被复用了三次 |
| `r` | 残差，即 $\hat\tau_{ext}$ | 第 ④ 行使用的是**上一步**的 $r$ |
| `ko` | $K_O$ 的对角元素 | 逐元素相乘，不是矩阵乘法 |

### 1.4 首次调用

```
① p = p(0)      ⑥ torque = f_0      ⑦ sum = p(0)      ⑧ tprev = f_0
⑨ p = p(0) − p(0) = 0      ⑩ r = 0      返回 0 ✓
```

第二次调用时 `sum = p(0) + Δt/2·(f_1 + f_0)`，正好是标准的梯形积分。

### 1.5 离散实现的等效动态

设外力为常值 $\tau_{ext}$，模型准确，并且梯形积分对 $p$ 是精确的，即 $p_k - p_{k-1} = \frac{\Delta t}{2}\big[(u_k + \tau_{ext}) + (u_{k-1} + \tau_{ext})\big]$，其中 $u = \tau - \tau_f - \beta$。由代码得

$$
r_k - r_{k-1} = K_O\Big[(p_k - p_{k-1}) - \tfrac{\Delta t}{2}(f_k + f_{k-1})\Big],\qquad f_k = u_k + r_{k-1}
$$

代入后，记误差 $e_k = r_k - \tau_{ext}$、$a = K_O\Delta t/2$：

$$
\boxed{\;e_k = (1-a)\,e_{k-1} - a\,e_{k-2}\;}
\tag{1.3}
$$

这是一个**二阶**差分方程。连续时间的一阶系统变成了离散二阶系统，原因是第 ④ 行在积分中使用了上一步的 $r_{k-1}$（一步延迟）。

### 1.6 离散稳定性：KΔt < 2

式 (1.3) 的特征方程为 $z^2 - (1-a)z + a = 0$。用 Jury 判据：

- $P(1) = 2a > 0$ ✓
- $P(-1) = 2 > 0$ ✓
- $|a_0| = a < 1$ $\Longleftrightarrow$ $K_O\Delta t < 2$

所以：

$$
\boxed{\;\text{稳定} \iff K_{O,i}\,\Delta t < 2\quad(\text{对每个关节})\;}
$$

✅ **数值验证**（[06 §4.3](06-测试与验证.md#43-动量观测器的稳定边界)，$\Delta t = 0.01$ s）：

| $K_O\Delta t$ | 0.50 | 1.50 | 1.90 | 1.99 | 2.01 | 2.10 | 2.50 |
|---|---|---|---|---|---|---|---|
| $\max\lvert\hat\tau\rvert$（真值 0.5） | 0.52 | 0.84 | 0.97 | 1.00 | 1.12 | 58.8 | $1.9\times10^9$ |
| 状态 | 正常 | 超调 | 振荡 | 几乎不衰减 | **发散** | **发散** | **发散** |

**实用建议**：取 $K_O\Delta t \le 0.5$。这时两个极点都是正实数（例如 $K_O\Delta t = 0.3$ 时极点为 0.6 和 0.25），没有振荡。

| 控制频率 | 稳定上限 $K_O < 2/\Delta t$ | 推荐上限 $K_O \le 0.5/\Delta t$ |
|---|---|---|
| 100 Hz | 200 | 50 |
| 500 Hz | 1000 | 250 |
| 1 kHz | 2000 | 500 |

> 早先的草稿文档把 “$K_O = 200$” 描述为“太快，放大噪声导致误报”。实际上在 100 Hz 下，$K_O = 200$ 正好落在**稳定边界**上。

### 1.7 调参

$K_O$ 决定了**响应速度与抗噪声能力之间的权衡**：

| $K_O$ | 时间常数 $1/K_O$ | 效果 |
|---|---|---|
| 10 | 100 ms | 平滑，但碰撞检测延迟大 |
| 30 | 33 ms | `test.cpp` 使用的值 |
| 50 | 20 ms | `test.m`、`test_rnea.cpp` 使用的值；100 Hz 下的推荐上限 |
| 更大 | 更短 | 噪声更大；还必须满足 $K_O\Delta t < 2$ |

**整定步骤**：从 $K_O = 0.1/\Delta t$ 开始，让机器人在无碰撞的情况下跑典型轨迹，观察 $\hat\tau_{ext}$ 的噪声水平；在噪声可以接受的前提下逐步增大，但不要超过 $0.5/\Delta t$。

### 1.8 RNEA 版差异

[momentum_observer_rnea.h:75-76](../lib/momentum_observer_rnea.h#L75-L76) 只有两行不同：

```cpp
p    = dyn->rnea(q, zero, qd);                                    // M·q̇
beta = dyn->rnea(q, zero, zero, GRAVITY) - dyn->tranCqd(q, qd);   // G − Cᵀq̇
```

其余代码逐字相同，多了一个常量成员 `zero`。**其他 RNEA 版观测器也都是这个模式**：只替换动力学量的获取方式，控制逻辑不变。

## 2. 扰动观测器 DisturbanceObserver

### 2.1 一览

| 项目 | 内容 |
|---|---|
| 文件 | [disturbance_observer.h](../lib/disturbance_observer.h)（101 行）、[disturbance_observer_rnea.h](../lib/disturbance_observer_rnea.h)（105 行） |
| 来源 | Mohammadi 等人的非线性扰动观测器 |
| 误差动态 | $\dot e = -kM^{-1}e + \dot\tau_{ext}$，收敛速率**随位形变化** |
| 参数 | `sigma`、`xeta`、`beta` 三个，但只合成一个 $k = \frac12(\xi + 2\beta\sigma)$ |
| 离散方法 | 后向欧拉（隐式），**对任何 $\Delta t$ 都稳定** |
| 每步计算 | 1 次 $M$、1 次 $C$、1 次 $G$，**2 次矩阵求逆** |
| 特点 | 唯一使用 $C\dot q$（不转置）的观测器，所以**不要求 $C$ 是 Christoffel 形式** |

### 2.2 为什么这里用的是 $C\dot q$ 而不是 $C^T\dot q$

动量观测器需要 $\dot p = \frac{d}{dt}(M\dot q)$，展开后出现 $\dot M$，才需要斜对称性把它换成 $C + C^T$。扰动观测器的辅助变量是 $Y\dot q$，其中 $Y$ 是**常数**矩阵，求导得到 $Y\ddot q$，不会出现 $\dot M$，所以直接使用动力学方程中的 $C\dot q$。

对照代码：扰动观测器写的是 `getC(q, qd)*qd`，其他观测器写的是 `getC(q, qd).transpose()*qd`。

### 2.3 理论

外部力矩（暂时忽略摩擦，最后再加回来）：

$$
\tau_{ext} = M\ddot q + C\dot q + G - \tau,\qquad M\ddot q = \tau + \tau_{ext} - C\dot q - G
\tag{2.1}
$$

引入内部状态 $z$ 和辅助变量 $p = Y\dot q$（$Y$ 为常数矩阵），令估计值为

$$
\hat\tau_{ext} = z + p
$$

希望估计误差满足一阶动态 $\dot{\hat\tau}_{ext} = L(\tau_{ext} - \hat\tau_{ext})$，其中 $L = YM^{-1}$。

由 $\dot p = Y\ddot q = YM^{-1}M\ddot q = L(\tau + \tau_{ext} - C\dot q - G)$，要求 $\dot z + \dot p = L\tau_{ext} - L(z + p)$，解出：

$$
\boxed{\;\dot z = -Lz + L\big(C\dot q + G - \tau - p\big)\;}
\tag{2.2}
$$

**验证**：把式 (2.2) 代回，
$\dot{\hat\tau} = \dot z + \dot p = -Lz + L(C\dot q + G - \tau - p) + L(\tau + \tau_{ext} - C\dot q - G) = -L(z+p) + L\tau_{ext}$ ✓

**稳态检验**：令 $\dot z = 0$，得 $\hat\tau = z + p = C\dot q + G - \tau$；而当 $\ddot q = 0$ 时，由式 (2.1) 有 $\tau_{ext} = C\dot q + G - \tau$。两者一致 ✓。

**稳定性**：误差 $e = \tau_{ext} - \hat\tau_{ext}$ 满足 $\dot e = -Le + \dot\tau_{ext}$。代码中 $Y = kI$，所以 $L = kM^{-1}$。由于 $M$ 对称正定、$k > 0$，$L$ 的特征值全为正，误差指数收敛。**收敛速率取决于 $M$ 的特征值**：惯量大的方向收敛慢，惯量小的方向收敛快。

### 2.4 隐式离散化

对式 (2.2) 使用后向欧拉：

$$
z_{k+1} = z_k + \Delta t\Big[-L z_{k+1} + L\big(C\dot q + G - \tau - p\big)\Big]
$$

$$
\Longrightarrow\quad (I + \Delta t\,L)\,z_{k+1} = z_k + \Delta t\,L\big(C\dot q + G - \tau - p\big)
\tag{2.3}
$$

这需要求解一个线性方程组，这就是代码中第二次矩阵求逆的来源。

对标量情形 $\dot z = -\lambda z$，后向欧拉给出 $z_{k+1} = z_k/(1 + \lambda\Delta t)$，极点 $\frac{1}{1+\lambda\Delta t} \in (0, 1)$，**对任何 $\Delta t > 0$ 都稳定**。

### 2.5 逐行代码

[disturbance_observer.h:73-92](../lib/disturbance_observer.h#L73-L92)：

```cpp
VectorJ DisturbanceObserver::getExternalTorque(VectorJ& q, VectorJ& qd, VectorJ& tau, double dt)
{
  L = Y * dyn->getM(q).inverse();          // ① L = Y·M⁻¹              （第 1 次求逆）
  L *= dt;                                 // ② ★ L ← Δt·L，之后所有 L 都已含 Δt
  p = Y * qd;                              // ③ p = Y·q̇

  if(isRun) {
    torque = tau - dyn->getFriction(qd);   // ④ τ − τ_f
    lft = I + L;                           // ⑤ I + Δt·L
    rht = z + L*(dyn->getC(q, qd)*qd + dyn->getG(q) - torque - p);   // ⑥ 式 (2.3) 右边
    z = lft.inverse() * rht;               // ⑦ 解方程组                （第 2 次求逆）
  } else {
    z = -p;                                // ⑧ 使 τ̂ = p + z = 0
    isRun = true;
  }

  p += z;                                  // ⑨ τ̂ = Y·q̇ + z
  return p;
}
```

- **第 ② 行最容易漏看**：执行之后 `L` 已经包含了 $\Delta t$，所以第 ⑤ 行的 `I + L` 就是 $I + \Delta t L$。
- 第 ⑥ 行中的 `torque` 是 $\tau - \tau_f$，这相当于在式 (2.2) 中把 $\tau$ 替换为 $\tau - \tau_f$，符号正确。
- `rht` 声明为 `MatrixJ`，但存放的是 $n\times 1$ 的向量，功能上没有问题。
- 首次调用时第 ①② 行计算的 `L` 没有被使用，浪费了一次矩阵求逆。
- 第 ⑦ 行用 `lft.lu().solve(rht)` 会更快、数值上也更稳定。

### 2.6 首次调用

```
③ p = Y·q̇      ⑧ z = −Y·q̇      ⑨ p + z = 0      返回 0 ✓
```

### 2.7 调参：三个参数只合成一个 k

[disturbance_observer.h:95-99](../lib/disturbance_observer.h#L95-L99)：

```cpp
double k = 0.5*(xeta + 2*beta*sigma);
Y = k * MatrixJ::Identity(jointNo, jointNo);
```

三个参数最终只合成一个标量 $k$，所以有无穷多种组合给出相同的结果。它们的 Doxygen 注释都是 `@param sigma ...`，作者没有写说明。

**实用建议**：固定 `sigma = 1, xeta = 0`，只调 `beta`，此时 $k = \beta$。

#### 测试参数下几乎是“无差拍”的

测试代码使用 `sigma = 21, xeta = 18, beta = 50`，得到 $k = 1059$。以 2 连杆模型在 $q = 0$ 的位形为例：

| $M$ 的特征值 | 收敛速率 $k/\lambda$ | 时间常数 | 离散极点 $\frac{1}{1 + \Delta t\,k/\lambda}$（$\Delta t = 0.01$） |
|---|---|---|---|
| 1.2735 | 832 /s | 1.2 ms | 0.107 |
| 0.1140 | 9291 /s | 0.11 ms | 0.011 |

✅ 已计算验证（[06 §4.4](06-测试与验证.md#44-扰动观测器的离散极点)）。时间常数远小于采样周期 10 ms，离散极点接近 0，也就是说**观测器几乎在一步之内就收敛到新值**，基本不起滤波作用，效果接近直接数值微分。在仿真中没有噪声，所以看起来效果很好；在真机上会把速度噪声几乎原样放大到输出。

**建议**：用于真机时，先计算典型位形下 $M$ 的最大特征值 $\lambda_{max}$，从 $k \approx (10\sim50)\cdot\lambda_{max}$ 开始调，这样最慢方向的时间常数约为 20~100 ms，与动量观测器的常用设置相当。

### 2.8 RNEA 版差异

[disturbance_observer_rnea.h:86](../lib/disturbance_observer_rnea.h#L86)：

```cpp
rht = z + L*(dyn->rnea(q, qd, zeros, GRAVITY) - torque - p);   // 一次调用得到 C·q̇ + G
```

仍然需要 `getM()`（基类实现，$n$ 次 RNEA），但不需要 `tranCqd()`，所以每步只有 $n + 1$ 次 RNEA 调用，是 RNEA 版中最少的。

## 3. 滑模观测器 SlidingModeObserver

### 3.1 一览

| 项目 | 内容 |
|---|---|
| 文件 | [sliding_mode_observer.h](../lib/sliding_mode_observer.h)（127 行）、[sliding_mode_observer_rnea.h](../lib/sliding_mode_observer_rnea.h)（127 行） |
| 来源 | Garofalo 等人，*Sliding mode momentum observers for estimation of external torques and joint acceleration*，2019 |
| 核心 | 广义 super-twisting 算法（带线性项），**有限时间收敛** |
| 参数 | 每个关节 4 个：$T_1, S_1, T_2, S_2$，通常取 $T_i = 2\sqrt{S_i}$，实际只调 $S_1, S_2$ |
| 离散方法 | 前向欧拉（显式） |
| 稳定条件（近似） | 在滑模面附近要求 $T_2 > (50S_1 + S_2)\Delta t$，否则出现小幅抖振（见 §3.6） |
| 每步计算 | 1 次 $M$、1 次 $C$、1 次 $G$，$n$ 次 `tanh`、$n$ 次 `sqrt` |

### 3.2 背景：super-twisting 算法

普通的滑模观测器使用 $\mathrm{sign}(\cdot)$ 函数，会产生高频切换（抖振）。**super-twisting** 是一种二阶滑模算法：把不连续的 sign 放在**积分**里，输出是连续的，同时保留了有限时间收敛和对扰动的鲁棒性。

### 3.3 理论

观测器估计动量 $\hat p$，定义动量误差 $\tilde p = \hat p - p$：

$$
\begin{aligned}
\dot{\hat p} &= (\tau - \tau_f) + C^T\dot q - G + \sigma - T_2\,\tilde p - T_1\sqrt{|\tilde p|}\,\mathrm{sign}(\tilde p)\\
\dot\sigma &= -S_1\,\mathrm{sign}(\tilde p) - S_2\,\tilde p
\end{aligned}
\tag{3.1}
$$

所有运算都是逐元素的。减去真实的动量方程 $\dot p = (\tau - \tau_f) + C^T\dot q - G + \tau_{ext}$，令 $\tilde\sigma = \sigma - \tau_{ext}$：

$$
\begin{aligned}
\dot{\tilde p} &= \tilde\sigma - T_2\tilde p - T_1\sqrt{|\tilde p|}\,\mathrm{sign}(\tilde p)\\
\dot{\tilde\sigma} &= -S_1\mathrm{sign}(\tilde p) - S_2\tilde p - \dot\tau_{ext}
\end{aligned}
\tag{3.2}
$$

这是广义 super-twisting 的标准形式。在增益足够大（特别是 $S_1$ 要大于 $|\dot\tau_{ext}|$ 的上界）的条件下，$(\tilde p, \tilde\sigma)$ 在**有限时间内**收敛到 0，即 **$\sigma \to \tau_{ext}$**。所以 $\sigma$ 就是外力估计，代码返回的正是它。

**只看线性部分**（$T_1 = S_1 = 0$）时，由式 (3.2) 得传递函数

$$
\frac{\sigma(s)}{\tau_{ext}(s)} = \frac{S_2}{s^2 + T_2 s + S_2}
$$

当 $T_2 = 2\sqrt{S_2}$ 时，分母为 $(s + \sqrt{S_2})^2$，是**临界阻尼**的二阶低通滤波器。这就是示例代码中 $T_2 = 2\sqrt{S_2}$ 的由来。非线性部分采用 $T_1 = 2\sqrt{S_1}$ 是同样形式的经验选择。

### 3.4 逐行代码

[sliding_mode_observer.h:91-125](../lib/sliding_mode_observer.h#L91-L125)：

```cpp
VectorJ SlidingModeObserver::getExternalTorque(VectorJ& q, VectorJ& qd, VectorJ& tau, double dt)
{
  p = dyn->getM(q) * qd;                 // ① p = M·q̇
  torque = tau - dyn->getFriction(qd);   // ② τ − τ_f

  if(!isRun) {
    sigma.setZero();                     // ③ σ(0) = 0
    p_hat = p;                           // ④ p̂(0) = p(0)，于是 p̃(0) = 0
    isRun = true;
  }

  p = p_hat - p;                         // ⑤ ★ p 被复用为动量误差 p̃
  for(int i = 0; i < jointNo; i++)
    spp(i) = tanh(p(i)*BIG);             // ⑥ tanh(50·p̃) ≈ sign(p̃)

  dp_hat = torque + dyn->getC(q, qd).transpose()*qd - dyn->getG(q) + sigma;   // ⑦
  for(int i = 0; i < jointNo; i++) {
    dp_hat(i) -= T2(i)*p(i);                           // ⑧ −T₂·p̃
    dp_hat(i) -= sqrt(fabs(p(i))) * T1(i) * spp(i);    // ⑨ −T₁·√|p̃|·sign(p̃)
  }
  for(int i = 0; i < jointNo; i++)
    dsigma(i) = -S1(i)*spp(i) - S2(i)*p(i);            // ⑩ σ̇

  p = sigma;                             // ⑪ ★ p 再次被复用，保存返回值
  p_hat += dt*dp_hat;                    // ⑫ 前向欧拉
  sigma += dt*dsigma;                    // ⑬ 前向欧拉
  return p;                              // 返回的是更新之前的 σ_k
}
```

**变量 `p` 在一次调用中有三种含义**，是全库最难读的地方：

| 位置 | `p` 的含义 |
|---|---|
| 第 ① 行之后 | 动量 $p = M\dot q$ |
| 第 ⑤ 行之后 | 动量误差 $\tilde p = \hat p - p$ |
| 第 ⑪ 行之后 | 返回值 $\sigma_k$ |

**`tanh(50x)` 代替 `sign(x)`**（`BIG = 50`，[sliding_mode_observer.h:55](../lib/sliding_mode_observer.h#L55)）：在 $|\tilde p| \lesssim 0.02$ 的“边界层”内，`tanh` 近似线性，从而避免了真正 sign 函数引起的剧烈抖振。第 106 行注释掉的代码就是真正的 sign 函数。

**返回值有一步延迟**：第 ⑪ 行在第 ⑬ 行之前，所以返回的是 $\sigma_k$ 而不是 $\sigma_{k+1}$。

### 3.5 首次调用

```
④ p̂ = p      ⑤ p̃ = 0      ⑥ spp = 0      ⑩ σ̇ = 0      ⑪ 返回 σ = 0 ✓
⑫ p̂ 按 ⑦ 的模型项前进一步
```

### 3.6 离散稳定性与抖振

在滑模面附近（$|\tilde p|$ 很小），$\tanh(50\tilde p) \approx 50\tilde p$，而 $\sqrt{|\tilde p|}\tanh(50\tilde p)$ 在 0 点的斜率为 0。于是式 (3.2) 近似为线性系统：

$$
s^2 + T_2 s + (50S_1 + S_2) = 0
$$

以测试参数 $S_1 = 15, S_2 = 10, T_2 = 2\sqrt{10} = 6.32$ 为例，自然频率 $\sqrt{760} \approx 27.6$ rad/s，阻尼比只有约 0.11，是一个**弱阻尼**系统。

前向欧拉对特征值 $\lambda$ 稳定的条件是 $|1 + \lambda\Delta t| < 1$，对这对复特征值等价于：

$$
T_2 > (50S_1 + S_2)\,\Delta t
$$

测试参数在 100 Hz 下：$6.32 < 7.6$（关节 1）、$6.32 < 10.1$（关节 2），**不满足**。于是在滑模面附近会形成一个小幅的极限环（离开边界层后 `tanh` 饱和，非线性项提供了额外的阻尼，所以不会发散）。

✅ **数值验证**：在没有外力的时段（0.5~0.9 s），估计值的波动幅度为：

| $\Delta t$ | 0.01 | 0.005 | 0.002 | 0.001 |
|---|---|---|---|---|
| 条件 $T_2 > (50S_1+S_2)\Delta t$（关节 1） | ❌ 6.32 < 7.60 | ✅ | ✅ | ✅ |
| 波动幅度（关节 1） | 0.0063 | 0.0024 | 0.0009 | 0.0004 |

影响不大（约为 0.5 N·m 外力的 1%），但说明**滑模观测器需要较高的控制频率**，或者较小的 $S_1$。

## 4. 卡尔曼观测器 DKalmanObserver

### 4.1 一览

| 项目 | 内容 |
|---|---|
| 文件 | [disturbance_kalman_filter.h](../lib/disturbance_kalman_filter.h)（127 行）、[disturbance_kalman_filter_rnea.h](../lib/disturbance_kalman_filter_rnea.h)（130 行） |
| 来源 | Hu 等人的扰动卡尔曼滤波器 |
| 核心 | 把外力建模为一个线性系统的输出，与动量一起组成增广状态，用卡尔曼滤波估计 |
| 参数 | $S$（外力动态）、$H$（外力输出矩阵）、$Q$（$2n\times 2n$，每步）、$R$（$n\times n$，每步） |
| 离散方法 | `KalmanFilter::step(u, y, dt)`：前向欧拉（$S = 0$ 时是精确的） |
| 每步计算 | 1 次 $M$、1 次 $C$、1 次 $G$，$2n\times 2n$ 矩阵运算若干，1 次 $n\times n$ 求逆 |

### 4.2 外力的“外部模型”

卡尔曼滤波需要一个状态演化模型。为此假设外力由一个自治线性系统产生：

$$
\dot\omega = S\,\omega,\qquad \tau_{ext} = H\,\omega
\tag{4.1}
$$

不同的 $S$ 表示对外力形态的不同先验假设：

| $S$ | $H$ | 假设 | 用途 |
|---|---|---|---|
| $0$ | $I$ | 外力**分段恒定**，变化由过程噪声驱动（随机游走） | 默认，所有测试都使用 |
| $-\lambda I$ | $I$ | 外力按指数衰减 | 冲击类外力 |
| $\begin{bmatrix}0 & I\\-\omega_0^2 I & 0\end{bmatrix}$ | $[I\;\;0]$ | 频率为 $\omega_0$ 的振动 | 已知频率的周期扰动（此时 $\omega$ 为 $2n$ 维，**当前代码不支持**，见下） |

> ⚠️ 代码把 $\omega$ 的维度固定为 $n$（状态向量 `X` 的长度是 `2*jointNo`，$S$、$H$ 都是 $n\times n$），所以上表最后一行这种需要 $2n$ 维 $\omega$ 的模型**不能直接使用**，需要修改代码。

### 4.3 增广系统

状态 $X = \begin{bmatrix}p\\\omega\end{bmatrix}\in\mathbb R^{2n}$，把动量方程和式 (4.1) 合并：

$$
\dot X = \underbrace{\begin{bmatrix}0 & H\\0 & S\end{bmatrix}}_{A}X + \underbrace{\begin{bmatrix}I\\0\end{bmatrix}}_{B}u,\qquad
y = \underbrace{\begin{bmatrix}I & 0\end{bmatrix}}_{C}X = p
\tag{4.2}
$$

其中 $u = \tau - \tau_f - G + C^T\dot q = \tau - \tau_f - \beta$ 是**已知输入**，“测量值”是动量 $p = M(q)\dot q$。

**$A, B, C$ 都是常数矩阵**：与位形相关的量全部放在了 $u$ 和 $y$ 里，每一步用当前的 $M, C, G$ 重新计算。所以卡尔曼滤波器可以在构造函数中一次建好。

### 4.4 逐行代码

**构造函数**（[disturbance_kalman_filter.h:66-90](../lib/disturbance_kalman_filter.h#L66-L90)）按式 (4.2) 搭建 $A, B, C$：

```cpp
MatrixJ A(2*jointNo, 2*jointNo), B(2*jointNo, jointNo), C(jointNo, 2*jointNo);
B.setZero();  C.setZero();
for(int i = 0; i < jointNo; i++) { B(i, i) = 1; C(i, i) = 1; }   // B = [I; 0]，C = [I 0]
A.setZero();
A.block(      0, jointNo, jointNo, jointNo) = h;                 // A 右上 = H
A.block(jointNo, jointNo, jointNo, jointNo) = s;                 // A 右下 = S
filter = new KalmanFilter(A, B, C);
filter->setCovariance(q, r);
```

**每步**（[disturbance_kalman_filter.h:99-119](../lib/disturbance_kalman_filter.h#L99-L119)）：

```cpp
p = dyn->getM(q) * qd;                          // ① 测量 y = p = M·q̇
u = tau - dyn->getG(q) - dyn->getFriction(qd);  // ② u = τ − G − τ_f
u += dyn->getC(q, qd).transpose() * qd;         // ③ u += Cᵀq̇，即 u = τ − τ_f − β

if(isRun) {
  X = filter->step(u, p, dt);                   // ④ 三参数版本：A 按连续时间处理 ✓
} else {
  X.setZero();
  for(int i = 0; i < jointNo; i++) X(i) = p(i); // ⑤ X₀ = [p(0); 0]
  filter->reset(X);                             // ⑥ 同时 P₀ = 0
  isRun = true;
}
p = H * X.block(jointNo, 0, jointNo, 1);        // ⑦ τ̂ = H·ω̂（取 X 的后 n 个元素）
return p;
```

- 第 ④ 行必须用三参数的 `step`，因为传入的 $A$ 是连续时间矩阵（见 [04 §3.2](04-基础组件.md#32-两个-step-重载对-a-的假设相反)）；
- 首次调用不执行滤波，只初始化，返回 $H\cdot 0 = 0$ ✓；
- `X.block(jointNo, 0, jointNo, 1)` 等价于更易读的 `X.tail(jointNo)`。

### 4.5 可观性

可观性矩阵为

$$
\mathcal O = \begin{bmatrix}C\\CA\\CA^2\\\vdots\end{bmatrix} = \begin{bmatrix}I & 0\\0 & H\\0 & HS\\\vdots & \vdots\end{bmatrix}
$$

所以**增广系统可观 $\iff$ $(S, H)$ 可观**。$H = I$ 时无条件可观，这是 $H = I$ 作为默认值的原因；如果 $H$ 奇异（例如只想估计部分关节的外力），必须检查 $(S,H)$ 的可观性，否则部分外力分量无法估计。

### 4.6 与动量观测器的关系

取默认的 $S = 0,\ H = I$。每一步的滤波过程是：

1. **预测**：$\hat p^- = \hat p + \Delta t(u + \hat\omega)$，即用当前的外力估计外推动量；
2. **新息**：$\nu = p_{测} - \hat p^-$，即“实测动量比模型预测多出来的部分”，这就是未建模力矩的证据；
3. **更新**：$\hat\omega \leftarrow \hat\omega + K_\omega\nu$。

这与动量观测器“用动量残差驱动外力估计”的思想完全一样，区别只在于增益：

| | 增益 | 特点 |
|---|---|---|
| 动量观测器 | 人工设定的常数 $K_O$ | 一阶低通 |
| 卡尔曼观测器 | 卡尔曼增益，由 $Q, R$ 和协方差 $P$ 自动计算，稳态时收敛到 Riccati 方程的解 | 稳态为**二阶**低通（状态有 $p$ 和 $\omega$ 两个） |

可以把卡尔曼观测器理解为“**根据噪声统计自动确定增益的动量观测器**”。使用者要提供的是 $Q, R$（噪声特性），而不是直接给出增益。

增益中把动量残差引向外力估计的，是协方差的非对角块 $P^{\omega p}$。它之所以不为零，是因为 $A$ 的右上块 $H$ 在预测步中把 $\omega$ 的不确定性“传递”给了 $p$。

### 4.7 调参

测试参数（[tests/test.cpp:47-53](../tests/test.cpp#L47-L53)、[matlab/test.m:88-91](../matlab/test.m#L88-L91)）：

```matlab
S = zeros(n);    H = eye(n);
Q = blkdiag(0.002*eye(n), 0.3*eye(n));    % 前 n 个对应动量，后 n 个对应外力
R = 0.05*eye(n);
```

| 参数 | 含义 | 调大的效果 |
|---|---|---|
| $Q$ 的动量块（0.002） | 对动力学模型的不信任程度 | 更依赖测量 |
| $Q$ 的外力块（0.3） | 外力突变的可能性 | **响应更快**，噪声更大 |
| $R$（0.05） | 动量测量的噪声 | 输出更平滑，响应更慢 |

- 结果只取决于 $Q$ 与 $R$ 的**相对**大小，两者同时乘以同一个倍数，结果不变。
- ⚠️ $Q$、$R$ 都是**每步**的值（[04 §3.3](04-基础组件.md#33-q-没有随-dt-缩放)）。控制频率改变后，要按 $Q \propto \Delta t$、$R \propto 1/\Delta t$ 重新换算。

### 5.2 代码中的三处差异

[disturbance_kalman_filter_exp.h:103-126](../lib/disturbance_kalman_filter_exp.h#L103-L126)：

```cpp
M = dyn->getM(q);                  // ① 缓存 M（要用两次）

u += dyn->getC(q, qd).transpose() * qd;
```

`updateR(M)` 的意义：用户给出的 $R$ 是**速度**的测量噪声，动量 $p = M\dot q$ 的噪声协方差为 $MRM^T$，随位形变化（推导见 [04 §4.6](04-基础组件.md#46-测量噪声-r-的处理)）。

### 5.3 在 S = 0 时，两种卡尔曼观测器的真正区别

[04 §4.5](04-基础组件.md#45-5-项泰勒级数在默认配置下是精确的) 证明了：当 $S = 0$ 时，$A$ 是幂零矩阵，前向欧拉离散的 $A_d$、$B_d$ 与精确离散**完全相同**。所以两者真正的区别只有：

| | `DKalmanObserver` | `DKalmanObserverExp` |
|---|---|---|
| $Q_d$ | $Q$（每步给定） | $\begin{bmatrix}Q_p\Delta t + Q_\omega HH^T\frac{\Delta t^3}{3} & Q_\omega H\frac{\Delta t^2}{2}\\ Q_\omega H^T\frac{\Delta t^2}{2} & Q_\omega\Delta t\end{bmatrix}$（设 $Q = \mathrm{diag}(Q_p, Q_\omega)$） |
| $R_d$ | $R$（常数） | $M(q)\,R\,M(q)^T/\Delta t$（随位形变化） |

$Q_d$ 的非对角块 $Q_\omega H\Delta t^2/2$ 描述了“外力变化会导致动量变化”的相关性。以测试参数为例（$Q_\omega = 30$，$\Delta t = 0.01$），它等于 0.0015，与对角块 $Q_p\Delta t = 0.002$ 同一量级，**不可忽略**。

### 5.4 两套参数为什么差 100 倍

测试代码中两种观测器的参数：

| | $Q$ 动量块 | $Q$ 外力块 | $R$ |
|---|---|---|---|
| `DKalmanObserver`（每步） | 0.002 | 0.3 | 0.05 |
| `DKalmanObserverExp`（每秒） | 0.2 | 30 | 0.0005 |

在 $\Delta t = 0.01$ 时：

- $Q_{Exp}\cdot\Delta t = 0.2\times0.01 = 0.002$，$30\times0.01 = 0.3$，正好等于 Euler 版的 $Q$；
- $R_{Exp}/\Delta t = 0.0005/0.01 = 0.05$，正好等于 Euler 版的 $R$（Exp 版还要再乘以 $MM^T$）。

✅ **两套参数是严格对应的**：它们描述的是同样的噪声假设，只是一个按“每步”、一个按“每秒”表达。

**换算规则**：$Q_{每步} = Q_{每秒}\cdot\Delta t$，$R_{每步} = R_{谱密度}/\Delta t$。

## 6. 滤波动力学观测器 FDynObserver

### 6.1 一览

| 项目 | 内容 |
|---|---|
| 文件 | [filtered_dyn_observer.h](../lib/filtered_dyn_observer.h)（62 行）、[filtered_dyn_observer_rnea.h](../lib/filtered_dyn_observer_rnea.h)（63 行） |
| 核心 | 只求外力的**低通滤波值**，利用恒等式 $\frac{\omega s}{s+\omega} = \omega - \frac{\omega^2}{s+\omega}$ 把微分消掉 |
| 等效传递函数 | $\hat\tau_{ext} = \frac{\omega}{s+\omega}\tau_{ext}$，**与 $K_O = \omega$ 的动量观测器完全相同** |
| 参数 | 截止频率 $\omega$（**rad/s**，参数名误写为 `cutOffHz`） |
| 离散方法 | 双线性变换 + 预畸变，**对任何 $\Delta t$ 都稳定** |
| 每步计算 | 1 次 $M$、1 次 $C$、1 次 $G$，2 个一阶滤波器，2 次 `tan` |

### 6.2 理论：用滤波器恒等式吸收微分

由动量方程，

$$
\tau_{ext} = \dot p + \big(\tau_f + G - C^T\dot q - \tau\big)
$$

$\dot p$ 不能直接计算。但碰撞检测本来就需要对结果做低通滤波，那么就只求

$$
\hat\tau_{ext} = W(s)\,\tau_{ext},\qquad W(s) = \frac{\omega}{s+\omega}
$$

展开后第一项是 $W(s)\,s\,p$，含有微分。关键的代数恒等式：

$$
\boxed{\;\frac{\omega\,s}{s+\omega} = \frac{\omega(s+\omega) - \omega^2}{s+\omega} = \omega - \frac{\omega^2}{s+\omega}\;}
$$

于是

$$
\hat\tau_{ext} = \underbrace{\omega\,p}_{\text{代数项}} + \underbrace{\frac{-\omega^2}{s+\omega}\,p}_{F_2(s)\,p} + \underbrace{\frac{\omega}{s+\omega}\big(\tau_f + G - C^T\dot q - \tau\big)}_{F_1(s)(\cdots)}
\tag{6.1}
$$

**微分消失了**，只剩下一个代数项和两个稳定的一阶滤波器。这就是 [04 §2.4](04-基础组件.md#24-filterf2-的推导) 中那个形式奇怪的 `FilterF2` 存在的原因。

### 6.3 逐行代码

[filtered_dyn_observer.h:41-60](../lib/filtered_dyn_observer.h#L41-L60)：

```cpp
VectorJ FDynObserver::getExternalTorque(VectorJ& q, VectorJ& qd, VectorJ& tau, double dt)
{
  p = dyn->getM(q) * qd;                                // ① p = M·q̇

  if(isRun) {
    res = f2.filt(p, dt) + f2.getOmega() * p;           // ② F₂(s)·p + ω·p
    p = dyn->getFriction(qd) + dyn->getG(q) - dyn->getC(q, qd).transpose() * qd;   // ③ 复用 p
    p -= tau;                                           // ④ τ_f + G − Cᵀq̇ − τ
    res += f1.filt(p, dt);                              // ⑤ + F₁(s)·(...)
  } else {
    f2.set(p);                                          // ⑥ F₂ 设为稳态
    p = dyn->getFriction(qd) + dyn->getG(q) - dyn->getC(q, qd).transpose() * qd;
    p -= tau;
    f1.set(p);                                          // ⑦ F₁ 设为稳态
    res.setZero();                                      // ⑧ 首次返回 0
    isRun = true;
  }
  return res;
}
```

第 ②⑤ 行合起来正好是式 (6.1)。`getOmega()` 返回的是原始截止频率 $\omega$（[04 §2.7](04-基础组件.md#27-getomega-返回的是-ω-而不是-ω_w)）。

### 6.4 首次调用与启动

首次调用把两个滤波器设为各自输入的稳态（[04 §2.5](04-基础组件.md#25-直流增益与-set消除启动瞬态)），并返回 0。第二次调用时，如果状态变化不大，输出约为 $-\omega_w p + \omega p + (\ldots) \approx$ 真实值，**没有启动尖峰**。

### 6.5 与动量观测器的等价性

[02 §5.1](02-理论基础.md#51-一个重要结论动量观测器与-fdyn-在连续时间上完全等价) 证明了：取 $K_O = \omega$ 时，动量观测器与 FDyn 在连续时间上是**同一个算子**，对模型误差的反应也完全相同。

| | 动量观测器 | FDyn |
|---|---|---|
| 离散方法 | 梯形积分 + 一步延迟 | 双线性变换 |
| 稳定条件 | $K_O\Delta t < 2$ | 无条件稳定 |
| 初始状态 | $r = 0$ | 滤波器处于稳态 |
| 变步长 | 自然支持 | 每步重新计算系数（多 2 次 `tan`） |
| `dt = 0` | 安全 | ⚠️ 产生 NaN（[08 P3](08-已知问题与修复建议.md#p3-dt--0-导致-nan-永久污染)） |

所以“FDyn 是纯前馈、抗模型误差能力差，动量观测器有反馈、更鲁棒”的说法并不成立。两者对模型误差同样敏感，**这也正是需要 `dynamic_calibration` 提供准确参数的原因**。

### 6.6 调参

只有一个参数 $\omega$（rad/s），相当于动量观测器的 $K_O$：

- 测试值 $\omega = 8$ rad/s（约 1.27 Hz，时间常数 125 ms）；
- $\omega$ 越大，响应越快，噪声也越大。

⚠️ 构造函数 `FDynObserver(rd, cutOffHz, sampHz)` 的两个参数名都不对，实际是**截止频率（rad/s）**和**采样周期（s）**。测试中写的是 `FDynObserver(&robot, 8, TSTEP)`，其中 `TSTEP = 0.01`。

## 7. 范围观测器 FRangeObserver

### 7.1 一览

| 项目 | 内容 |
|---|---|
| 文件 | [filtered_range_observer.h](../lib/filtered_range_observer.h)（66 行） |
| 作用 | **不估计外力**，而是估计“模型有 $k$ 的相对误差时，FDyn 的输出会偏离多少”，用作**自适应阈值** |
| 参数 | $\omega$、$\Delta t$（与配套的 FDyn 相同）、模型相对误差 $k$（如 ±0.1） |
| RNEA 版 | 无 |

### 7.2 与 FDyn 的两处差异

[filtered_range_observer.h:44-64](../lib/filtered_range_observer.h#L44-L64) 与 FDyn 几乎逐字相同，只有两处不同：

```cpp
p = dyn->getM(q) * qd;
p *= shift;                     // ① 所有模型项都乘以 k
...
p = dyn->getFriction(qd) + dyn->getG(q) - dyn->getC(q, qd).transpose() * qd;
p *= shift;                     // ① 同上
res += f1.filt(p, dt);          // ② 没有 p -= tau
```

输出为

$$
\text{res} = k\cdot W(s)\Big(\dot p + \tau_f + G - C^T\dot q\Big)
$$

### 7.3 为什么这样算

FDyn 的输出对模型是线性的：$\hat\tau_{ext} = W(s)\big(\text{模型项}\big) - W(s)\,\tau$。如果所有模型项都有相对误差 $k$，那么 FDyn 输出的偏差就是 $k\cdot W(s)(\text{模型项})$，这正是 FRange 的输出。

- **乘以 $k$**：模型项按比例缩放；
- **不含 $\tau$**：$\tau$ 是测量值，与模型误差无关。

### 7.4 用法：自适应阈值

[matlab/test.m:147-169](../matlab/test.m#L147-L169) 展示了用法：创建 $k = +0.1$ 和 $k = -0.1$ 两个实例，与 FDyn 的输出画在一起。

```matlab
id_dr1 = calllib('observers','configFilterRangeObserver',-1,cutOff,timeStep, delta);   % +10%
id_dr2 = calllib('observers','configFilterRangeObserver',-1,cutOff,timeStep,-delta);   % −10%
```

由于 FRange 对 $k$ 是线性的，$k$ 取 $\pm0.1$ 的两个输出**互为相反数**，所以实际上只需要一个实例：

$$
\text{阈值}_i(t) = \big|\text{res}_i(t)\big|_{k=0.1},\qquad
\text{碰撞判据：}\ \big|\hat\tau_{ext,i}\big| > \text{阈值}_i + \text{常数余量}
$$

> ⚠️ 注意：`ext_up`（$k = +0.1$）**并不总是**在 `ext_low`（$k = -0.1$）上方。当模型项为负时两者会交换位置，所以应该使用绝对值，而不是直接把 `ext_up` 当作上界。

**常数余量**用来覆盖与运动状态无关的误差（如测量噪声、摩擦模型误差）。机器人静止时模型项只剩 $G$，阈值仍然与 $|G|$ 成比例，这可能偏小或偏大，所以常数余量必不可少。

### 7.5 调参

- $k$ 取你对模型相对误差的估计。跑过 `dynamic_calibration` 且验证误差 `rre` 较低时可以取 5%~10%；使用 URDF 标称参数时应取 20% 以上。
- $\omega$ 和 $\Delta t$ **必须与配套的 FDyn 完全一致**，否则阈值和被比较的信号不在同一个频带上。

## 8. 横向对比与选型

### 8.1 特性对比

| 观测器 | 等效动态 | 离散稳定性 | 可调参数 | 需要 Christoffel $C$ | 每步成本 | `dt=0` |
|---|---|---|---|---|---|---|
| 动量 | 一阶 $K_O$ | $K_O\Delta t < 2$ | $n$ 个 $K_O$ | ✅ | ★ | 安全 |
| 扰动 | 一阶，速率 $kM^{-1}$ | 无条件稳定 | 1 个 $k$ | ❌ | ★★★ | 安全 |
| 滑模 | 有限时间 + 二阶线性 | 近似 $T_2 > (50S_1+S_2)\Delta t$ | $S_1, S_2$ | ✅ | ★★ | 安全 |
| 卡尔曼 | 二阶，增益自动 | 与 Riccati 相关 | $Q, R$（每步） | ✅ | ★★★ | 安全 |
| 卡尔曼（精确） | 同上 | 同上 | $Q, R$（每秒） | ✅ | ★★★★ | ⚠️ 除以 0 |
| FDyn | 一阶 $\omega$（= 动量） | 无条件稳定 | 1 个 $\omega$ | ✅ | ★ | ⚠️ NaN |
| FRange | 阈值 | 无条件稳定 | $\omega, k$ | ✅ | ★ | ⚠️ NaN |

### 8.2 该选哪个

| 场景 | 推荐 |
|---|---|
| 刚开始用，想要简单可靠 | **动量观测器**，$K_O \le 0.5/\Delta t$ |
| 控制频率不稳定，担心稳定性 | **FDyn**（与动量观测器等价，但无条件稳定）；务必过滤 `dt = 0` |
| 需要随工况变化的碰撞阈值 | **FDyn + FRange**（论文推荐的组合） |
| 了解噪声统计，或者想建模外力的先验动态 | **卡尔曼观测器** |
| 需要有限时间收敛的理论保证 | **滑模观测器**，需要较高控制频率 |
| 手头的 $C$ 不是 Christoffel 形式，又没有 RNEA | **扰动观测器**（只用 $C\dot q$），但要把 $k$ 调小 |
| 精确离散卡尔曼 | 先修复 [08 P1](08-已知问题与修复建议.md#p1-kalmanfiltercontinous-读取未初始化内存) |
