## 1. 仿真场景

所有示例都使用同一个场景。

### 1.1 机器人模型：平面 2 连杆

[tests/double_link.h](../tests/double_link.h)，参数写死在构造函数中：

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| $m_1, m_2$ | 1 kg | $l_1, l_2$ | 0.5 m |
| $l_{c1}, l_{c2}$（质心位置） | 0.25 m | $I_1, I_2$ | 0.3、0.2 kg·m² |
| 摩擦 | **0**（`getFriction` 返回零向量） | 重力 | 9.81 m/s²，竖直向下；$q_1 = 0$ 时连杆 1 水平 |

$$
M(q) = \begin{bmatrix}
m_1l_{c1}^2 + m_2(l_1^2 + l_{c2}^2 + 2l_1l_{c2}\cos q_2) + I_1 + I_2 & m_2(l_{c2}^2 + l_1l_{c2}\cos q_2) + I_2\\
m_2(l_{c2}^2 + l_1l_{c2}\cos q_2) + I_2 & m_2l_{c2}^2 + I_2
\end{bmatrix}
$$

$$
C = \begin{bmatrix} h\dot q_2 & h(\dot q_1+\dot q_2)\\ -h\dot q_1 & 0\end{bmatrix},\quad h = -m_2l_1l_{c2}\sin q_2;\qquad
G = g\begin{bmatrix}(m_1l_{c1} + m_2l_1)\cos q_1 + m_2l_{c2}\cos(q_1+q_2)\\ m_2l_{c2}\cos(q_1+q_2)\end{bmatrix}
$$

- $C$ 是标准的 Christoffel 形式 ✅；
- `getC()` 中没有给 `C(1,1)` 赋值，它依靠构造函数中的 `C.setZero()` 保持为 0（正确，但如果以后有人修改初始化，这里会出错）；
- [tests/double_link_rnea.h](../tests/double_link_rnea.h) 用同样的公式实现了 `rnea()`，并正确处理了 `g` 参数。

### 1.2 轨迹

两个关节分别做不同频率的正弦运动（[tests/test.cpp:80-86](../tests/test.cpp#L80-L86)）：

$$
q_1 = \sin(1.3t),\qquad q_2 = \sin(0.8t),\qquad t\in[0, 3)\ \text{s},\quad \Delta t = 0.01\ \text{s}
$$

$\dot q$、$\ddot q$ 都是**解析**求出的，没有噪声。

### 1.3 注入外力

[tests/test.cpp:89-95](../tests/test.cpp#L89-L95)：

```cpp
tau = robot.getM(q)*q2d + robot.getC(q,qd)*qd + robot.getG(q);   // 无外力时的理想力矩
if(t > 1 && t < 2) {
  tau(0) -= 0.5;
  tau(1) -= 0.5;
}
```

**符号推导**：观测器看到的电机力矩比维持该运动所需的力矩少了 0.5。由 $M\ddot q + C\dot q + G = \tau + \tau_{ext}$：

$$
\tau_{ext} = \underbrace{M\ddot q + C\dot q + G}_{\tau_{理想}} - (\tau_{理想} - 0.5) = +0.5
$$

**正确的输出**：两个关节都在 1~2 s 内输出约 **+0.5** 的方波，其余时间为 0。

`make test` 还会生成 `input.csv`，这个文件正是 [matlab/input.csv](../matlab/input.csv)。✅ 已核实：该文件有 301 行（$t = 0$ 到 $3.00$，浮点累加多出一行），$t = 1.5$ 时的力矩比理想值正好小 0.5。

### 2.2 用 include guard 选择观测器

`test.cpp` 通过注释和取消注释 `#include` 来选择观测器，配置代码用头文件的 include guard 作为开关：

```cpp
#include "../lib/sliding_mode_observer.h"     // 定义了宏 SLIDING_MODE_OBSERVER_H
...
#ifdef SLIDING_MODE_OBSERVER_H                // 这个观测器被 include 了才编译下面的配置
  VectorJ T1(2), S1(2), T2(2), S2(2);
  ...
#endif
```

这样不需要额外的配置宏。但要注意：

- 被 `#ifdef` 排除的代码**不参与编译**，所以其中残留的旧类型名 `Vector`/`Matrix` 一直没有被发现（[08 P5](08-已知问题与修复建议.md#p5-示例中未启用的分支无法编译)）；
- 可以同时启用多个观测器（它们在同一个 `.cpp` 中，不违反 ODR），但输出文件只保留**最后一个**观测器的结果，因为每个 `#ifdef` 块都给同一个变量 `ext` 赋值。

### 2.3 test_kalman.cpp

单独验证 `KalmanFilter`：一个 2 状态、1 输出的线性系统，输入为 $\sin 2t$，测量噪声为 ±0.02 的均匀分布。注意它**事先手动离散化**了系统（`A = I + DELTA*A`），然后使用**两参数**的 `step(u, y)`，这与观测器的用法（连续 $A$ + 三参数 `step`）正好相反。

## 3. MATLAB 对比实验

### 3.1 C 接口

[matlab/observers.h](../matlab/observers.h) 定义了一组 `extern "C"` 函数：

| 函数 | 说明 |
|---|---|
| `configMomentumObserver(index, k)` 等 7 个 `config*` | `index = -1`：新建观测器，返回句柄；`index ≥ 0`：修改已有观测器的参数 |
| `getExternalTorque(index, ext, q, qd, tau, dt)` | 计算外力，结果写入 `ext` |
| `reset(index)` | 重置指定观测器 |
| `freeAll()` | 释放所有观测器 |
| `getRobotTorque(tau, q, qd, q2d)` | 用内置模型计算逆动力学（含摩擦） |

**返回值**：非负数为句柄；`-1` 表示索引错误（`ERR_WRONG_INDEX`），`-2` 表示句柄表已满（`ERR_NO_SLOTS`，最多 30 个），`-3` 表示句柄与观测器类型不匹配（`ERR_WRONG_TYPE`）。注意输入的 `-1`（`ADD_NEW`）与输出的 `-1`（错误）数值相同但含义不同。

**矩阵参数**按 **MATLAB 的列主序**展开：`[1 2; 3 4]` 传进来是 `{1, 3, 2, 4}`（[matlab/observers.cpp:193-205](../matlab/observers.cpp#L193-L205)）。

### 3.2 test.m 的流程

[matlab/test.m](../matlab/test.m) 在同一份数据上依次运行各观测器：

```matlab
loadlibrary('observers.so','observers.h')
data = csvread('input.csv');                 % t, q(2), qd(2), tau(2)
K = [1,1];                                   % 电流→力矩的驱动增益（仿真数据已经是力矩，所以取 1）
res = libpointer('doublePtr', zeros(1,JNT)); % 输出缓冲区

id = calllib('observers','configMomentumObserver',-1,[50,50]);
for i = 2:size(cur,1)                        % 从第 2 行开始，用相邻时间戳计算 dt
    calllib('observers','getExternalTorque',id,res,q(i,:),qd(i,:),K.*cur(i,:),tm(i)-tm(i-1));
    ext(i,:) = res.Value(:);
end
...
calllib('observers','freeAll');
unloadlibrary('observers');
```

| 段落 | 观测器 | 参数 | 状态 |
|---|---|---|---|
| 27-42 行 | 动量 | $K_O$ = [50, 50] | 运行 |
| 44-62 行 | 扰动 | σ=21, ξ=18, β=50 | 运行 |
| 64-83 行 | 滑模 | $S_1$=[20,30]，$S_2$=[10,10] | 运行 |
| 85-104 行 | 卡尔曼 | $Q$=diag(0.002, 0.3)，$R$=0.05 | 运行 |
| 106-126 行 | 精确离散卡尔曼 | $Q$=diag(0.2, 30)，$R$=0.0005 | **整段注释掉** |
| 128-145 行 | FDyn | ω=8 rad/s，T=0.01 s | 运行 |
| 147-169 行 | FRange ×2 | k=±0.1 | 运行，与 FDyn 画在同一张图里 |

`K.*cur(i,:)` 这一行就是 `ext_observer` 与 `dynamic_calibration` 的接合点：在真机上，`K` 应该换成 `estimate_drive_gains` 辨识出的驱动增益。

### 3.3 test_lib.cpp

[matlab/test_lib.cpp](../matlab/test_lib.cpp) 用 C++ 调用 `observers.so`，读取 `input.csv`，运行精确离散卡尔曼观测器，写出 `external.csv`。它在第一行传入 `dt = 0`（[test_lib.cpp:61-66](../matlab/test_lib.cpp#L61-L66)），因为第一次调用只做初始化、不使用 `dt`，所以这是安全的。

## 4. Python 数值复现

### 4.1 说明

由于当前环境没有 C++ 编译器和 Eigen，本文档用纯 Python 逐行复现了 5 个观测器（动量、扰动、滑模、FDyn、欧拉离散卡尔曼）的离散算法，以及测试中的 2 连杆模型和仿真场景。

```bash
cd docs/verify
python observer_sim.py        # Python 2.7 或 3.x 均可，无第三方依赖
```

复现代码与 C++ 源码的对应关系在每个类的注释中注明。以下结果均来自该脚本。

### 4.2 外力恢复

期望：0.5 s 和 2.5 s 时约为 0，1.5 s 时约为 0.5。

| 观测器 | 参数 | t=0.5 | t=1.5 | t=2.5 | 最大值 |
|---|---|---|---|---|---|
| 动量 | $K_O$=30 | 0.000 / 0.000 | 0.500 / 0.500 | 0.000 / 0.000 | 0.500 |
| 扰动 | 21/18/50 | 0.011 / 0.004 | 0.496 / 0.499 | −0.012 / −0.004 | 0.503 |
| 滑模 | $S_1$=[15,20]，$S_2$=[10,10] | −0.009 / −0.008 | 0.494 / 0.509 | 0.022 / −0.007 | 0.573 |
| FDyn | ω=8 | −0.006 / −0.003 | 0.492 / 0.491 | 0.015 / 0.011 | 0.505 |
| 卡尔曼（欧拉） | 测试参数 | 0.012 / 0.004 | 0.496 / 0.499 | −0.010 / −0.003 | 0.499 |

✅ 所有观测器都能恢复外力。动量观测器几乎没有误差，是因为仿真数据是解析的，梯形积分在这种光滑信号上非常精确。

### 4.3 动量观测器的稳定边界

理论（[05 §1.6](05-观测器详解.md#16-离散稳定性kδt--2)）：稳定 $\iff K_O\Delta t < 2$。$\Delta t = 0.01$：

| $K_O\Delta t$ | 0.50 | 1.50 | 1.90 | 1.99 | 2.01 | 2.10 | 2.50 |
|---|---|---|---|---|---|---|---|
| t=2.5 时的输出（真值 0） | 0.000 | 0.000 | −0.139 | 0.262 | 0.749 | −14.97 | $-2.9\times10^{6}$ |
| 最大值（真值 0.5） | 0.522 | 0.844 | 0.974 | 0.997 | 1.12 | 58.8 | $1.9\times10^{9}$ |

✅ 边界两侧的行为与理论完全吻合：1.99 时振荡几乎不衰减，2.01 时开始发散。

### 4.4 扰动观测器的离散极点

测试参数 $k = 1059$，2 连杆在 $q = 0$ 处：

| $M$ 的特征值 | $k/\lambda$ | 离散极点（$\Delta t = 0.01$） |
|---|---|---|
| 1.2735 | 832 /s | 0.1073 |
| 0.1140 | 9291 /s | 0.0106 |

极点接近 0，观测器几乎一步收敛，基本不起滤波作用（[05 §2.7](05-观测器详解.md#27-调参三个参数只合成一个-k)）。

### 4.5 动量观测器与 FDyn 的等价性

让“真实”机器人的动力学比观测器模型整体大 10%（制造模型误差），外力仍为 1~2 s 的 +0.5。取 $K_O = \omega = 8$，从 $t = 1$ s 开始比较（避开两者初始化方式不同导致的启动瞬态）：

| $\Delta t$ | 动量观测器最大误差 | FDyn 最大误差 | 两者输出之差的最大值 |
|---|---|---|---|
| 0.01 | 0.9337 | 0.9263 | 0.0283 |
| 0.001 | 0.9320 | 0.9318 | **0.0023** |

✅ 两者对模型误差的反应几乎完全相同，差异随 $\Delta t$ 减小而减小，说明差异只来自离散化方法。同时也可以看到，**10% 的模型误差带来了约 0.93 N·m 的虚假外力**，比真实外力 0.5 N·m 还大。这说明准确的动力学参数和自适应阈值有多重要。

## 5. 现有测试的局限

| 局限 | 后果 |
|---|---|
| **没有断言**，只画图 | 回归问题无法自动发现 |
| **无噪声**：$q, \dot q$ 都是解析值 | 看不出各观测器抗噪声能力的差异（这恰恰是它们的主要区别） |
| **模型完全准确** | 看不出模型误差的影响（§4.5 表明它可能是主要误差源） |
| **没有摩擦** | 真机上摩擦是最大的建模误差之一 |
| **只有 2 个关节，平面运动** | 没有覆盖 6 轴的计算量、空间运动和奇异位形 |
| **定步长** | 没有测试 `dt` 抖动和 `dt = 0`（[08 P3](08-已知问题与修复建议.md#p3-dt--0-导致-nan-永久污染)） |
| **一次只能测一个观测器** | 不方便横向对比（MATLAB 封装弥补了这一点） |

## 6. 建议补充的测试

1. **自动判定**：在 1.2~1.8 s 内检查 $|\hat\tau - 0.5| < \epsilon$，在其余时段检查 $|\hat\tau| < \epsilon$；
2. **噪声鲁棒性**：给 $\dot q$ 加高斯噪声，比较各观测器输出的标准差；
3. **模型误差**：像 §4.5 那样用不同的模型生成数据和运行观测器；
4. **变步长与异常步长**：随机抖动的 `dt`，以及 `dt = 0`；
5. **RNEA 一致性**：同一个机器人，检查 M/C/G 版和 RNEA 版的输出差异在 $10^{-6}$ 量级；
6. **Christoffel 检查**：对用户实现的 `getC()` 用 [02 §4.4](02-理论基础.md#44-检验方法) 的方法做数值检验；
7. **真实数据**：使用 `dynamic_calibration/dataset_ur10e/collision/` 中的推动实验数据（两个 CSV），配合辨识出的参数，验证在真机数据上的检测效果。
