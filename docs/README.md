## 这个库是做什么的

机械臂在运行中受到的外力（例如撞到人或物体）会体现为关节上的**外部力矩** $\tau_{ext}$。这个库**不需要力矩传感器**，只根据以下信息估计 $\tau_{ext}$：

- 关节位置 $q$、关节速度 $\dot q$
- 电机力矩 $\tau$（由电流乘以驱动增益得到）
- 机器人动力学模型 $M(q)$、$C(q,\dot q)$、$G(q)$ 和摩擦模型

$\tau_{ext}$ 一旦超过阈值，就可以判定发生了碰撞。

它和同目录下的 [dynamic_calibration](../../dynamic_calibration/) 项目共同支撑同一篇论文：

```
dynamic_calibration ──(动力学参数 π、驱动增益 K、摩擦参数)──▶ ext_observer ──▶ τ̂_ext ──▶ 碰撞检测
```

> Mamedov S., Mikhel S. *Practical Aspects of Model-Based Collision Detection*. Frontiers in Robotics and AI, 2020.

库中实现了 **7 种观测器**，全部遵循同一个接口：

```cpp
VectorJ getExternalTorque(VectorJ& q, VectorJ& qd, VectorJ& tau, double dt);
```

## 七个观测器一览

| 观测器 | 类名（M/C/G 版 / RNEA 版） | 思路 | 可调参数 | 离散方法 | 每步成本 |
|---|---|---|---|---|---|
| 动量观测器 | `MomentumObserver` / `…Rnea` | 积分反馈，残差是 $\tau_{ext}$ 的一阶低通 | $K_O$（每关节一个） | 梯形积分 | 最低 |
| 扰动观测器 | `DisturbanceObserver` / `…Rnea` | $M^{-1}$ 加权的一阶误差动态 | 3 个参数，实际合成 1 个 $k$ | 后向欧拉（隐式） | 高（2 次求逆） |
| 滑模观测器 | `SlidingModeObserver` / `…Rnea` | super-twisting，有限时间收敛 | $S_1, S_2$（$T_i = 2\sqrt{S_i}$） | 前向欧拉 | 中 |
| 卡尔曼观测器 | `DKalmanObserver` / `…Rnea` | 把外力当作状态，做最优估计 | $S, H, Q, R$ | 前向欧拉 | 高 |
| 卡尔曼（精确离散） | `DKalmanObserverExp` / 无 | 同上 + Van Loan 离散 + 位形相关的 $R$ | $S, H, Q, R$ | 矩阵指数 | 最高 |
| 滤波动力学 | `FDynObserver` / `…Rnea` | 用滤波器恒等式消去微分，纯前馈 | 截止频率 $\omega$ | 双线性变换 | 低 |
| 范围观测器 | `FRangeObserver` / 无 | 估计模型误差带，作为自适应阈值 | $\omega$、误差比例 $k$ | 双线性变换 | 低 |

## 本文档新增的核实结论

以下结论是本文档相对仓库自带说明（以及早先的 `CODE_WALKTHROUGH.md` 草稿）**新增或更正**的内容，全部有数值或代码证据：

| 结论 | 证据 | 详见 |
|---|---|---|
| 动量观测器的离散实现**只有在 $K_O\Delta t < 2$ 时才稳定**。在 100 Hz 下 $K_O = 200$ 就发散了，而不只是“太灵敏” | 特征方程推导 + 数值扫描 | [05 §1.6](05-观测器详解.md#16-离散稳定性kδt--2) |
| 使用 M/C/G 接口时，`getC()` **必须**满足 $\dot M = C + C^T$（Christoffel 形式），否则 $C^T\dot q$ 是错的；RNEA 路线天然不受这个限制 | 推导 | [03 §3.2](03-架构与接口.md#32-getc-必须满足斜对称性) |
| `dt = 0` 会让 FDyn/FRange **永久输出 NaN**（`FilterF2` 中出现 $\infty\cdot 0$），精确离散的卡尔曼观测器也会除以 0 | 代码 + IEEE 754 | [08 P3](08-已知问题与修复建议.md#p3-dt--0-导致-nan-永久污染) |
| 测试中的扰动观测器参数（$k = 1059$）使离散极点只有 0.01~0.11，**几乎是无差拍的**，实际上接近直接数值微分 | 特征值计算 | [05 §2.7](05-观测器详解.md#27-调参三个参数只合成一个-k) |
| 两个卡尔曼观测器的测试参数**严格等价**：$Q_{Euler} = Q_{Exp}\cdot\Delta t$，$R_{Euler} = R_{Exp}/\Delta t$ | 代数 + 数值 | [05 §5.4](05-观测器详解.md#54-两套参数为什么差-100-倍) |
| `tests/observers.cpp` 按**行主序**读矩阵，`matlab/observers.cpp` 按**列主序**读矩阵，对非对称的 $S$、$H$ 结果互为转置 | 代码对比 | [08 P9](08-已知问题与修复建议.md#p9-两份-observerscpp-的矩阵读取顺序不同) |
| 所有观测器都能在测试场景中恢复 +0.5 N·m 的外力方波 | Python 逐行复现 | [06 §4](06-测试与验证.md#4-python-数值复现) |

- **代码位置**写作 `文件:行号`，都是可点击的相对链接，指向仓库当前版本。
- **单位**：角度 rad，角速度 rad/s，力矩 N·m，时间 s，截止频率 **rad/s**（不是 Hz，见 [08 P4](08-已知问题与修复建议.md#p4-cutoffhz--samphz-参数名与实际单位不符)）。
