## 1. RNEA 辅助算法

### 1.1 问题

RNEA（递归牛顿-欧拉算法）是动力学库最常提供的接口，它是一个“黑盒”：

$$
\texttt{rnea}(q,\dot q,\ddot q,g) = M(q)\ddot q + C(q,\dot q)\dot q + G_g(q)
$$

而观测器需要的是 $M\dot q$、$G$、$C^T\dot q$，有时还需要完整的 $M$。`RobotDynamicsRnea` 基类只要求用户实现 `rnea()`，其余的量都由它通过**巧妙地组合 RNEA 调用**得到。

### 1.2 基本技巧：利用线性

RNEA 对 $\ddot q$ 是**线性**的，所以把任意向量 $x$ 放在加速度的位置，并令 $\dot q = 0$、$g = 0$：

$$
\texttt{rnea}(q, 0, x, 0) = M(q)\,x
$$

- 取 $x = \dot q$，得到**动量** $p = M\dot q$。这就是代码中反复出现的 `rnea(q, zero, qd)`，**速度被放在加速度的位置上**，第一次读时很容易看不懂。
- 取 $x = e_i$（第 $i$ 个单位向量），得到 **$M$ 的第 $i$ 列**。

### 1.3 getM()：逐列拼出惯性矩阵

[robot_dynamics_rnea.cpp:37-55](../lib/robot_dynamics_rnea.cpp#L37-L55)：

```cpp
MatrixJ RobotDynamicsRnea::getM(VectorJ& q)
{
  int N = jointNo();
  _zero.resize(N);  _zero.setZero();
  _M.resize(N, N);
  _qext.resize(N);
  for(int i = 0; i < N; i++) {
    _qext.setZero();              // _qext 在这里被用作单位向量 e_i
    _qext(i) = 1;
    _p0 = rnea(q, _zero, _qext);  // _p0 在这里被用作 M 的第 i 列
    for(int j = 0; j < N; j++)
      _M(j, i) = _p0(j);
  }
  return _M;
}
```

- 成本：$n$ 次 RNEA 调用。
- 成员变量 `_qext`、`_p0` 被**复用**成了与名字无关的含义（“扩展的 q”被当作单位向量，“初始动量”被当作矩阵的一列），读的时候要注意。
- 内层循环可以简化为 `_M.col(i) = _p0;`。

### 1.4 tranCqd()：用数值差分求 $C^T\dot q$

RNEA 只能给出向量 $C\dot q$，拿不到矩阵 $C$，自然也就无法转置。代码利用斜对称性绕开了这个问题：

$$
C^T\dot q = \dot M\dot q - C\dot q
$$

$C\dot q$ 可以由 `rnea(q, qd, 0)` 得到。$\dot M\dot q$ 用链式法则展开，再用前向差分近似：

$$
\dot M\dot q = \sum_{i=1}^n \Big(\frac{\partial M}{\partial q_i}\dot q\Big)\dot q_i
\approx \sum_{i=1}^n \frac{M(q+\delta e_i)\dot q - M(q)\dot q}{\delta}\,\dot q_i
$$

其中每个 $M(\cdot)\dot q$ 都是一次 `rnea(·, 0, qd)` 调用。

[robot_dynamics_rnea.cpp:16-34](../lib/robot_dynamics_rnea.cpp#L16-L34)：

```cpp
VectorJ RobotDynamicsRnea::tranCqd(VectorJ& q, VectorJ& qd)
{
  int N = jointNo();
  _zero.resize(N);  _zero.setZero();
  _p0 = rnea(q, _zero, qd);                    // ① M(q)·q̇，差分的基准点
  _sum.resize(N);  _sum.setZero();
  for(int i = 0; i < N; i++) {
    _qext = q;
    _qext(i) += delta;                         // ② q + δ·e_i
    _sum += (rnea(_qext, _zero, qd) - _p0) * (qd(i) / delta);   // ③ 累加得到 Ṁ·q̇
  }
  _sum -= rnea(q, qd, _zero);                  // ④ 减去 C·q̇
  return _sum;                                 // ⑤ = Ṁq̇ − Cq̇
}
```

- 成本：$1 + n + 1 = n + 2$ 次 RNEA 调用（6 轴为 8 次）。
- ⚠️ 注释 `// M'*qd - C*qd` 中的 `M'` 表示**时间导数** $\dot M$，不是转置。

#### 为什么 RNEA 路线不依赖 Christoffel 形式

`tranCqd` 实际计算的是 $\dot M\dot q - c(q,\dot q)$，其中 $c = C\dot q$ 是 RNEA 给出的科氏/离心力矩**向量**，它是唯一确定的，与矩阵 $C$ 怎样分解无关。

回看动量方程推导中的式 (3.2)（[02 §3.1](02-理论基础.md#31-推导)）：

$$
\dot p = \dot M\dot q - C\dot q + \tau - \tau_f - G + \tau_{ext}
$$

观测器真正需要的正是 $\dot M\dot q - C\dot q$ 这个组合。所以：

- **RNEA 路线**直接计算了这个组合，**对任何正确的 RNEA 实现都成立**；
- **M/C/G 路线**用 $C^T\dot q$ 来代替它，这一步用到了 $\dot M = C + C^T$，所以**要求 $C$ 是 Christoffel 形式**。

函数名 `tranCqd`（“transpose C times qd”）只在 Christoffel 意义下才名副其实。

### 1.5 差分步长 delta

前向差分的误差由两部分组成：截断误差约为 $O(\delta)$，舍入误差约为 $O(\epsilon/\delta)$（$\epsilon \approx 2.2\times10^{-16}$）。两者平衡时 $\delta^* \approx \sqrt\epsilon \approx 1.5\times10^{-8}$。代码默认 $\delta = 10^{-7}$（[external_observer.h:136](../lib/external_observer.h#L136)），与最优值同一量级，相对误差约为 $10^{-7}$ 量级，对观测器来说完全足够。可以用 `setDelta()` 修改。

> 如果你的 RNEA 实现内部是单精度（float），最优步长约为 $\sqrt{1.2\times10^{-7}} \approx 3\times10^{-4}$，此时必须调用 `setDelta(3e-4)` 之类的值，否则差分结果全是噪声。

### 1.6 RNEA 路线的计算量

| 观测器（RNEA 版） | 每步 RNEA 调用 | 6 轴 |
|---|---|---|
| 动量、滑模、卡尔曼、FDyn | $M\dot q$：1，$G$：1，`tranCqd`：$n+2$ | **10** |
| 扰动 | `getM`：$n$，$C\dot q + G$：1 | **7**（另加 2 次矩阵求逆） |

`tranCqd` 内部已经算过一次 `rnea(q, 0, qd)`（即 $M\dot q$），而观测器在外面又算了一次，存在重复计算。代码中的 `// TODO: call it once` 注释说明作者也意识到了可以优化。

## 2. IIR 滤波器

### 2.1 概览

[iir_filter.h](../lib/iir_filter.h) 定义了一个抽象基类和 5 个滤波器：

| 类 | 连续传递函数 | 被使用？ | 备注 |
|---|---|---|---|
| `FilterF1` | $\dfrac{\omega}{s+\omega}$ | ✅ FDyn、FRange | 有变步长版本和 `set()` |
| `FilterF2` | $\dfrac{-\omega^2}{s+\omega}$ | ✅ FDyn、FRange | 有变步长版本和 `set()` |
| `FilterButterworth` | 二阶 Butterworth 低通 | ❌ | 状态没有初始化，也没有 `set()` |
| `FilterLowPass` | $\dfrac{\omega}{s+\omega}$ | ❌ | 与 `FilterF1` 的系数完全相同 |
| `FilterHighPass` | $\dfrac{s}{s+\omega}$ | ❌ | |

所有滤波器都是**逐元素**的：对向量的每个分量独立滤波，状态也是向量。

### 2.2 双线性变换与预畸变

双线性变换（Tustin 变换）把连续传递函数转换为离散传递函数：

$$
s \;\longleftarrow\; \frac{2}{T}\cdot\frac{1-z^{-1}}{1+z^{-1}}
$$

它把 $s$ 平面的左半平面映射到 $z$ 平面的单位圆内，所以**稳定性保持不变**。但频率轴会被非线性压缩：连续频率 $\omega_a$ 与离散频率 $\omega_d$ 满足 $\omega_a = \frac{2}{T}\tan\frac{\omega_d T}{2}$。

为了让离散滤波器的截止频率**正好**等于期望的 $\omega$，要先对 $\omega$ 做**预畸变**：用 $\omega_w = \frac{2}{T}\tan\frac{\omega T}{2}$ 代替 $\omega$ 进行变换。代码中所有滤波器的第一行都是：

```cpp
double omega = tan(cutOff * sampTime * 0.5);    // Ω = tan(ωT/2)，于是 ω_w = (2/T)·Ω
```

下文记 $\Omega = \tan(\omega T/2)$。当 $\omega T \ll 1$ 时 $\Omega \approx \omega T/2$，$\omega_w \approx \omega$。

### 2.3 FilterF1 的推导

$$
H_1(s) = \frac{\omega_w}{s + \omega_w}
\;\xrightarrow{\text{代入}}\;
H_1(z) = \frac{\Omega(1+z^{-1})}{(1+\Omega) + (\Omega - 1)z^{-1}}
$$

写成差分方程：

$$
y_k = \underbrace{\frac{1-\Omega}{1+\Omega}}_{k_1}\,y_{k-1} + \underbrace{\frac{\Omega}{1+\Omega}}_{k_2}\,(x_k + x_{k-1})
$$

代码完全一致（[iir_filter.h:122-136](../lib/iir_filter.h#L122-L136)）：

```cpp
void FilterF1::update(double cutOff, double sampTime) {
  double omega = tan(cutOff*sampTime*0.5);   // Ω
  k1 = (1-omega) / (1+omega);
  k2 = omega / (1 + omega);
  cut = cutOff;                              // 保存原始 ω，变步长版本要用
}
Eigen::VectorXd FilterF1::filt(Eigen::VectorXd& x) {
  y1 = k1*y1 + k2*(x + x1);                  // x1 = x_{k-1}，y1 = y_{k-1}
  x1 = x;
  return y1;
}
```

### 2.4 FilterF2 的推导

$$
H_2(s) = \frac{-\omega_w^2}{s+\omega_w}
\;\xrightarrow{\text{代入}}\;
H_2(z) = \frac{-f_2\,\Omega^2(1+z^{-1})}{(1+\Omega)+(\Omega-1)z^{-1}},\qquad f_2 = \frac{2}{T}
$$

（分子中的 $\omega_w^2 = f_2^2\Omega^2$，约去分母中的一个 $f_2$ 后剩下 $f_2\Omega^2$。）

$$
y_k = k_1\,y_{k-1} + \underbrace{\frac{-f_2\Omega^2}{1+\Omega}}_{k_2}(x_k + x_{k-1})
$$

与 `FilterF1` 相比只有 $k_2$ 不同，`filt()` 的代码逐字相同（[iir_filter.h:147-163](../lib/iir_filter.h#L147-L163)）。

**为什么需要这样一个奇怪的传递函数**：它来自恒等式 $\frac{\omega s}{s+\omega} = \omega - \frac{\omega^2}{s+\omega}$，用来在 FDyn 中“吸收”微分，见 [05 §6.2](05-观测器详解.md#62-理论用滤波器恒等式吸收微分)。

### 2.5 直流增益与 set()：消除启动瞬态

离散滤波器的直流增益（令 $z = 1$）：

$$
H_1(1) = \frac{2k_2}{1-k_1} = 1, \qquad H_2(1) = \frac{2k_2}{1-k_1} = -f_2\Omega = -\omega_w
$$

`set(x0)` 把滤波器状态直接设为“输入长期保持 $x_0$ 时”的稳态：

```cpp
inline void FilterF1::set(Eigen::VectorXd& x0) { x1 = x0; y1 = x0; }                // 稳态输出 = 1·x0
inline void FilterF2::set(Eigen::VectorXd& x0) { x1 = x0; y1 = -f2*omega*x0; }     // 稳态输出 = −ω_w·x0
```

✅ 两者都与离散直流增益严格一致。如果不这样初始化，滤波器从零状态开始，输出会有一个明显的启动尖峰，可能触发误报警。

### 2.6 变步长版本

实际控制循环的 `dt` 会有抖动，所以观测器调用的是 `filt(x, dt)`：它先用当前 `dt` 重新计算系数，再调用定步长的 `filt(x)`（[iir_filter.h:138-145](../lib/iir_filter.h#L138-L145)、[165-173](../lib/iir_filter.h#L165-L173)）。

- 这也是为什么要保存原始截止频率 `cut`：每一步都要用它重新计算 $\Omega$；
- 构造函数中的 `sampTime` 只影响 `set()` 使用的初始系数；第一次 `filt(x, dt)` 之后就被实际 `dt` 覆盖了；
- 代价是每步每个滤波器多 1 次 `tan()`。

### 2.7 getOmega() 返回的是 ω 而不是 ω_w

```cpp
inline double getOmega() const noexcept { return cut; }     // iir_filter.h:55
```

它返回原始截止频率 $\omega$（`cut`），而不是类中同样叫 `omega` 的成员 $\Omega = \tan(\omega T/2)$，**名字容易误导**。

FDyn 用它计算代数项 $\omega\,p$，而 `FilterF2` 内部的极点是预畸变后的 $\omega_w$。两者不严格相等，所以恒等式 $\omega - \frac{\omega^2}{s+\omega}$ 在离散实现中留下一个很小的残差：当动量 $p$ 恒定时，FDyn 的输出为 $(\omega - \omega_w)\,p$ 而不是 0。

以测试参数 $\omega = 8$ rad/s、$T = 0.01$ s 为例，$\omega_w = 8.00427$，残差系数为 $-0.00427$，相对于 $\omega p$ 只有 **0.05%**，实际可以忽略。如果追求严格，可以把代数项改成 $\omega_w p$（即 `f2*omega*p`）。

### 2.8 dt = 0 会产生 NaN

在 `FilterF2::filt(x, dt)` 中，如果 `dt = 0`：

```cpp
f2 = 2/dt;                         // = +∞
omega = tan(cut*dt*0.5);           // = 0
k2 = -f2*omega*omega/(1+omega);    // = −∞ × 0 = NaN
```

NaN 进入 `y1` 之后会**永久**传播，此后 FDyn/FRange 每一步都输出 NaN，直到调用 `reset()`。当两个采样的时间戳相同时（例如驱动器重复发送了同一帧）就会发生这种情况。**调用方必须保证 `dt > 0`**，见 [08 P3](08-已知问题与修复建议.md#p3-dt--0-导致-nan-永久污染)。

### 2.9 未使用的滤波器

- `FilterButterworth`：二阶 Butterworth，系数推导正确，但**状态向量 `x1, x2, y1, y2` 从未初始化**（`VectorXd(N)` 不会清零），也没有 `set()`。如果要使用，必须先手动清零。
- `FilterLowPass`：与 `FilterF1` 的系数和差分方程完全相同，属于重复代码。
- `FilterHighPass`：$\frac{s}{s+\omega}$，$k_2 = \frac{1}{1+\Omega}$，$y_k = k_1 y_{k-1} + k_2(x_k - x_{k-1})$。推导正确，但未被使用。

另外，基类 `FilterIIR` 没有虚析构函数。由于所有滤波器都是观测器的值成员，不会通过基类指针删除，所以目前不会出问题。

## 3. 离散卡尔曼滤波器 KalmanFilter

### 3.1 标准方程

系统模型：

$$
X_k = A X_{k-1} + B u_k + w_k,\quad w_k\sim\mathcal N(0,Q);\qquad
y_k = C X_k + v_k,\quad v_k\sim\mathcal N(0,R)
$$

| 步骤 | 公式 | 代码（[kalman_filter.h:119-132](../lib/kalman_filter.h#L119-L132)） |
|---|---|---|
| 状态预测 | $\hat X^- = A\hat X + Bu$ | `X = A * X + B * u;` |
| 协方差预测 | $P^- = APA^T + Q$ | `P = A * P * A.transpose() + Q;` |
| 新息协方差 | $S = CP^-C^T + R$ | `Y = C * (P * C.transpose()) + R;` |
| 卡尔曼增益 | $K = P^-C^TS^{-1}$ | `K = P * (C.transpose() * Y.inverse());` |
| 状态更新 | $\hat X = \hat X^- + K(y - C\hat X^-)$ | `X += K * (y - C * X);` |
| 协方差更新 | $P = (I - KC)P^-$ | `P = (I - K * C) * P;` |

注意变量命名：成员 `Y` 是**新息协方差** $S$，参数 `y` 才是**测量值**，两者仅大小写不同。

### 3.2 两个 step() 重载对 A 的假设相反

| 重载 | 对 `A`、`B` 的假设 | 内部处理 | 使用者 |
|---|---|---|---|
| `step(u, y)` | 已经是**离散**的 | 直接使用 | [tests/test_kalman.cpp](../tests/test_kalman.cpp)（事先手动做了 `A = I + DELTA*A`） |
| `step(u, y, dt)` | **连续**时间的 | `At = I + dt*A`，`B` 乘以 `dt`（前向欧拉） | `DKalmanObserver` |

两个重载名字相同、签名只差一个参数，**用错了不会有任何提示**。

### 3.3 Q 没有随 dt 缩放

[kalman_filter.h:138-142](../lib/kalman_filter.h#L138-L142)：

```cpp
At = I + dt*A;
X = At * X + dt * (B * u);
P = At * P * At.transpose() + Q;      // A、B 都按 dt 离散化了，Q 却原样使用
```

所以 `Q` 的含义是“**每一步**的过程噪声协方差”，而不是“每秒”。**控制周期一改变，`Q` 就必须重新整定**。`R` 同样是每步的测量噪声协方差。

### 3.4 P₀ = 0

`reset(x0)` 把 $P$ 设为零矩阵（[kalman_filter.h:112-116](../lib/kalman_filter.h#L112-L116)），表示“对初始状态完全确定”。第一次预测后 $P^- = Q$，不确定性随即被注入，所以只会让最初几步的响应略慢。

### 3.5 数值稳定性

- 协方差更新使用简化形式 $(I-KC)P$ 而不是 Joseph 形式 $(I-KC)P(I-KC)^T + KRK^T$。简化形式只在 $K$ 是最优增益时成立，舍入误差累积后 $P$ 可能逐渐失去对称性。长时间运行时可以定期执行 `P = 0.5*(P + P.transpose())`。
- `Y.inverse()` 是显式求逆，对 $n\le 6$ 的小矩阵问题不大；更稳妥的写法是 `Y.ldlt().solve(...)`。

## 4. 连续系统卡尔曼滤波器 KalmanFilterContinous

### 4.1 与 KalmanFilter 的区别

构造时传入的是**连续时间**的 $A, B, C$ 和**连续时间**的噪声强度 $Q, R$。每一步根据实际 `dt` 做**精确离散化**：

| 量 | `KalmanFilter::step(u, y, dt)` | `KalmanFilterContinous::step(u, y, dt)` |
|---|---|---|
| $A_d$ | $I + A\Delta t$ | $e^{A\Delta t}$ |
| $B_d$ | $B\Delta t$ | $\int_0^{\Delta t}e^{A\tau}d\tau\,B$ |
| $Q_d$ | $Q$（不缩放） | $\int_0^{\Delta t}e^{A\tau}Qe^{A^T\tau}d\tau$ |
| $R_d$ | $R$（不缩放） | $R_{upd}/\Delta t$ |

### 4.2 用增广矩阵一次求出 $A_d$ 和 $B_d$

$$
\exp\left(\begin{bmatrix}A & B\\0 & 0\end{bmatrix}\Delta t\right) = \begin{bmatrix}A_d & B_d\\0 & I\end{bmatrix}
$$

构造函数中搭好增广矩阵 `AB`，`makeDiscrete()` 中取出对应的块（[kalman_filter_continous.cpp:40-45](../lib/kalman_filter_continous.cpp#L40-L45)、[88-92](../lib/kalman_filter_continous.cpp#L88-L92)）。

### 4.3 Van Loan 方法求 $Q_d$

构造 $2n_a\times 2n_a$ 的矩阵并求指数：

$$
\exp\left(\begin{bmatrix}-A & Q\\0 & A^T\end{bmatrix}\Delta t\right)
= \begin{bmatrix}F_{11} & F_{12}\\0 & F_{22}\end{bmatrix},\qquad
F_{22} = A_d^T,\quad F_{12} = A_d^{-1}Q_d
$$

于是 $Q_d = F_{22}^T F_{12}$，对应代码：

```cpp
AQd = exponential(AQ, dt);
Qd = AQd.block(na, na, na, na).transpose() * AQd.block(0, na, na, na);   // F22ᵀ · F12
```

`setCovariance(q, r)` 把 $Q$ 直接写进 `AQ` 的右上块（[kalman_filter_continous.cpp:57](../lib/kalman_filter_continous.cpp#L57)），类中没有单独的 `Q` 成员。

### 4.4 AQ 的左下块未初始化

[kalman_filter_continous.cpp:46-51](../lib/kalman_filter_continous.cpp#L46-L51)：

```cpp
// [-A Q; 0 A']
AQ.resize(na+na, na+na);                  // 从 1×1 扩到 2na×2na，重新分配内存，内容未初始化
AQ.block(0, 0, na, na) = -a;
AQ.block(0, na, na, na) = Qd;
AQ.block(na, na, na, na) = a.transpose();
//                                        ← 左下块从未赋值
```

注释写着左下块是 `0`，但代码中没有赋值；紧挨着的 `AB` 有 `setZero()`，`AQ` 却没有。Van Loan 公式依赖左下块为零，垃圾值会通过矩阵指数污染整个结果。**这是一个真实的缺陷**，修复方法是在 `resize` 后加一行 `AQ.setZero();`，见 [08 P1](08-已知问题与修复建议.md#p1-kalmanfiltercontinous-读取未初始化内存)。

### 4.5 5 项泰勒级数：在默认配置下是精确的

```cpp
#define EXP_TERMS 5
Eigen::MatrixXd KalmanFilterContinous::exponential(Eigen::MatrixXd& m, double dt) {
  Eigen::MatrixXd res = Eigen::MatrixXd::Identity(m.rows(), m.cols());
  Eigen::MatrixXd acc = res;
  for(int i = 1; i <= EXP_TERMS; i++) {
    acc *= m * (dt/i);        // acc = (m·dt)^i / i!
    res += acc;
  }
  return res;
}
```

一般情况下，截断的泰勒级数不是精确的矩阵指数。但在 `DKalmanObserverExp` 最常用的配置 **$S = 0$** 下，情况很特殊：

$$
A = \begin{bmatrix}0 & H\\0 & 0\end{bmatrix} \;\Longrightarrow\; A^2 = 0
$$

$A$ 是**幂零矩阵**。可以验证：

- 增广矩阵 $\begin{bmatrix}A & B\\0 & 0\end{bmatrix}$ 的平方为 0（因为 $AB = \begin{bmatrix}0&H\\0&0\end{bmatrix}\begin{bmatrix}I\\0\end{bmatrix} = 0$）；
- Van Loan 矩阵 $\begin{bmatrix}-A & Q\\0 & A^T\end{bmatrix}$ 的 4 次方为 0（对角块平方为 0，非对角块的展开式中每一项都至少含有 $A^2$ 或 $(A^T)^2$）。

所以 5 项泰勒级数**恰好等于**精确的矩阵指数（前提是左下块确实为 0，即修复了 §4.4）。只有当 $S \neq 0$ 且 $\|S\|\Delta t$ 较大时，截断误差才需要考虑。

> 同样的原因，在 $S = 0$ 时 `KalmanFilter` 的前向欧拉离散 $I + A\Delta t$、$B\Delta t$ 也是**精确的**。两种卡尔曼观测器在 $S=0$ 时的真正区别只在于 $Q$ 和 $R$ 的处理方式，见 [05 §5](05-观测器详解.md#5-卡尔曼观测器精确离散-dkalmanobserverexp)。

### 4.6 测量噪声 R 的处理

类中与 $R$ 相关的有 3 个成员，关系容易混淆：

| 成员 | 含义 | 何时更新 |
|---|---|---|
| `R` | 用户给定的**原始**测量噪声（在 `DKalmanObserverExp` 中是**速度**层面的噪声） | 构造时设为 $I$，`setCovariance()` 时更新 |
| `Rupd` | 经过变换的测量噪声 $mRm^T$ | 构造时设为 $I$；**只有** `updateR(m)` 会更新 |
| `Rd` | 离散化后的测量噪声 $R_{upd}/\Delta t$ | 每次 `step()` 时由 `makeDiscrete()` 计算 |

```cpp
void KalmanFilterContinous::updateR(Eigen::MatrixXd& m) { Rupd = m * R * m.transpose(); }
```

**`updateR` 的物理意义**：测量值是动量 $p = M(q)\dot q$，真正带噪声的是速度 $\dot q$（协方差 $R$）。对线性变换 $p = M\dot q$，协方差按 $\mathrm{Cov}(p) = M\,R\,M^T$ 传播（不需要高斯假设）。所以动量的测量噪声**随机器人位形变化**，惯量大的位形噪声也大。

⚠️ **注意**：`setCovariance()` 只更新 `R`，不更新 `Rupd`。如果使用者直接使用这个类而忘了调用 `updateR()`，那么 `Rupd` 一直是单位阵，设置的 `R` 完全不起作用。`DKalmanObserverExp` 每一步都调用 `updateR(M)`，所以不受影响。

**`Rd = Rupd / dt`**：把连续时间测量噪声的功率谱密度换算为离散采样的协方差，这是标准做法。`dt = 0` 时会除以 0。
